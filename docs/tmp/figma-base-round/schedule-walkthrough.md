## 名詞(本輪)

- **職責**:負責人 / 協同(程式固定,不放欄位管理)。
- **執行任務**:人力需求裡的一個位置 = 職責 + 任務內容(欄位管理「執行任務」:店內事務與帳目負責、店內事務);負責人 0–1 筆、協同 0–10 筆;一筆只填一個人。
- **排班填進執行任務**:`schedule_task_assignments`(taskId 唯一;一筆排班在同一筆人力需求只能填一筆,可以填進好幾筆不同的人力需求,例:一人顧兩台)。
- **畫休**:總稱,分「整天畫休」「時段不可排」兩種,都算畫休天數、畫休人數。
- **班別**:不用;改說人力需求 / 人力需求範本(範本簡稱)。
- **休息只在排班**:預設值由規則「預設休息」(依時數分級)決定,排班對話框可以改;人力需求與範本沒有休息。

## 本輪決定(10/16)

1. 「職責」只指負責人 / 協同;人力需求 = 一組執行任務;排班填進執行任務(一個任務一人,一筆排班在同一筆人力需求只能填一筆)。
2. 只留兩個對話框:人力需求對話框(SC-21a / b / c / d)、排班對話框(SC-04a–f,其中 SC-04e 分 ①②③ 三步;SC-19);拿掉 SC-16、SC-48、SC-49a / b、SC-52a / b、SC-53、SC-54。
3. 休息只在排班,預設值由規則「預設休息」決定;容器標題、手機卡片標題拿掉休息。
4. 時間涵蓋提示只給負責人;拿掉「另建一筆排班」。
5. 「上下班時間改用打卡時間」預設不勾,新權限 `schedule.manage.use-punch-time`(預設只有總部管理)。
6. 各檢視的點擊:缺額 → 新增排班、長條 / 格子 → 編輯排班、容器標題 / 標籤 → 人力需求、空白處 / 人力需求區空白格 → 新增人力需求;月檢視不排班。
7. 自動排班條件「允許同一人同時段填進多筆人力需求」預設不勾;檢核規則「同一時段兼多個崗位」提醒預設關閉,兩者各自設定。
8. 拿掉「+1 超過人力需求」:要多一人 = 加一筆協同任務。
9. 崗位不加簡稱;同格多筆時標籤上方寫崗位名稱。
10. 刪人力需求會讓排班變成零筆時一起刪除(已開班的擋下)。
11. 新增人力需求的入口在排班對話框「加入這天的人力需求」標題列最右邊 [新增一筆人力需求](清單最下面的 [+ 加入人力需求] 只加既有的),疊開共用的人力需求對話框(日期鎖定、時間帶入排班時間);[新增] 後回到排班對話框自動加一列,人力需求獨立存檔,排班取消也保留(Snackbar 提示)。
12. 每張畫面三尺寸;滑過畫面在手機用按下畫面;規則頁每格加手機呈現。
