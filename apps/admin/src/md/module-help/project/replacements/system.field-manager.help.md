# 欄位管理

## 這個模組做什麼

管理表單下拉選項的來源:欄位類別(如「性別」「示範分類」)與其下的選項。各模組的表單會引用這裡的選項。

畫面分兩邊:左邊是欄位類別,選一個類別,右邊就是它底下的選項表格。表格每一列的「顏色」是這個選項在其他畫面上的標籤顏色(例如排班的崗位、遊戲);「來源」告訴你這個選項是哪個組織加的 ——「全域」是系統統一提供、每個組織都有;「<組織名稱> 自訂」是那個組織自己加的,可能是你的組織,也可能是你的上層或下層組織。這些混在同一份清單裡,因為填表的人看到的就是這一份。

## 常用操作

- **檢視類別**:左邊列出全部類別。標「系統」的是系統內建的類別;標「已停用」的類別會變淡。沒有管理類別權限的人,類別清單是唯讀的,需要新增類別請聯絡系統管理員。
- **新增類別**(需要管理類別的權限):按「+ 新增類別」,填類別 key、名稱與說明。**key 是表單引用這個類別的代號**:只能用小寫英文、數字與單一的「-」(例如 `cuisine-type`),不能和既有的類別重複(已停用的也算),**建立後不能改**。格式不對或重複時,輸入框下方會直接提示,不用等送出。
- **編輯類別**:選好在這裡新增的類別後按右邊的「編輯類別」,可以改名稱與說明;key 只能看、不能改。
- **停用 / 啟用類別**:按右邊的「停用類別」或「啟用類別」,立即生效,不需確認。停用的類別不會再出現在表單設計的類別清單裡,**已經用到它的表單欄位照常顯示、照常可以填**;類別不提供刪除。
- **新增選項**:按「+ 新增自訂選項」,在選定的類別下新增你的組織的自訂選項,填顯示名稱、值、排序與描述。**值(value)是資料實際存下去的內容**,同一個類別裡不能和全域選項、上層組織加的選項或你已經加過的選項重複;重複時會標在「值」這一欄。
- **編輯選項**:改**你的組織自己加的**選項的顯示名稱、排序與描述。**值建立後不能改** —— 既有資料以它對照,改掉之後過去的資料就對不回來了;要換值請新增一個選項、把原本的停用。
- **設定顏色**:在選項列的「顏色」欄下拉,從十組顏色(藍、青、綠、萊姆、黃、橘、紅、粉、紫、灰)選一個,選完立即儲存;選「不設定」就清掉顏色。**只能從這十組選,不能自己輸入色碼**。沒有顏色的選項顯示「—」。
- **停用 / 啟用選項**:切換該列的開關,立即生效,不需確認。停用只影響**新的填寫**,既有資料不受影響。選項不提供刪除(刪掉之後過去的資料會失去對照)。

## 重要規則

- **系統類別由系統維護,不能修改**:標「系統」的類別是系統內建、其他功能會用到的,名稱、說明都不能改,也不能停用;畫面上不會出現它的「編輯類別」與「停用類別」。
- 標示「全域」的選項由系統管理員統一維護、隨系統更新:你可以使用它,但不能編輯,停用開關也是唯讀的 —— 那個開關一切下去是所有組織一起生效,不是只有你的組織。需要停用某個全域選項請聯絡系統管理員。
- **上層組織加的選項你看得到但不能改**:上層組織(一路到你所屬的最上層組織)加的選項會出現在你的清單上,讓你可以用它填表;但只有加它的那個組織能編輯或停用。這些列會變淡、開關是唯讀的,操作欄會寫「由 <組織名> 管理」。
- **下層組織加的選項也可能出現在你的清單上**,條件是你的組織開了「可以看下層組織的資料」;和上層的一樣,看得到但不能改。
- **你加的選項,你的下層組織也看得到**(他們同樣不能改),但旁邊的兄弟組織看不到。
- **顏色跟著選項走**:全域選項的顏色由系統管理員統一設定,所有組織看到的都一樣,你看得到但不能改;上層或下層組織加的選項,顏色也只有加它的那個組織能改。
- 這一頁能做什麼由你的角色決定:沒有編輯權限就只看得到顏色、沒有下拉;沒有新增權限就看不到「新增自訂選項」,沒有停用權限就只看得到狀態、沒有開關;沒有管理類別的權限就看不到「+ 新增類別」、「編輯類別」與停用類別的按鈕。
