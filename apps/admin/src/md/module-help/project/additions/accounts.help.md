# 帳戶管理

## 這個模組做什麼

管理錢的去向:**銀行帳戶**(每個帳戶的餘額與交易)、**即時現金帳**(每家分店的小金庫與收銀點抽屜裡現在應該有多少現金)、**待結清款項**(進貨單、調貨單還沒付清、還沒退或還沒收的錢)與**關帳**(每個月結束後把那個月的帳鎖住)。上方的分頁切換;你只看得到有權限的分頁,只剩一個時不會出現分頁。

## 側欄數字

側欄「帳戶管理」旁的數字,是**待結清款項**的筆數:一張單據有待付、待退或待收的每一邊各算一筆,只算你看得到的單據。

- **找出是哪幾筆**:就是「待結清款項」分頁列出的那些列。看不到這個分頁的人不會有這個數字。
- 滑鼠移到數字上(手機、平板請長按數字)會顯示這個數字算的是什麼。沒有就不顯示,超過 99 顯示「99+」。
- 付款、收到退款、收款、退款或沖正之後,數字會跟著更新。

## 常用操作

- **新增帳戶**:在「銀行帳戶」分頁按右上的「+ 新增帳戶」,填銀行代碼、分行、帳號、戶名、期初餘額與期初日期,並選**使用組織**(可以多個)。選最上層組織並勾「含下層」就是全部分店都能用。
- **看帳戶**:點列表上的一列進入帳戶詳情,上方是目前餘額與期間內的收、支合計,下方是交易清單;每一列的餘額是那一筆之後的餘額。可以用期間與類型篩選。
- **登記交易**:在帳戶詳情按「登記交易」,選類型、金額與時間。批貨、調貨要選歸屬分店;選「批貨收入」「調貨收入」時一定要選單據,清單裡只會出現還有錢要退或要收的單據。「調整」「其他」要自己選收或支,並寫說明。
- **沖正**:交易記錯了,按那一列的「沖正」並寫原因。系統會寫一筆方向相反、金額相同的交易,原本那筆保留並標示「已沖正」。
- **設定使用組織**:在帳戶詳情按「設定使用組織」。只有使用組織包含你所在分店的帳戶,你才看得到,付款時也才選得到。
- **即時現金帳**:選分店後,上方是小金庫與每個開班中收銀點抽屜目前應有的金額,下方是那一天的現金流水(投庫、出庫、存銀行、調貨、退貨退款、現金更正),可以再用類型、收銀點篩選。這一頁只能查看。
- **待結清款項**:每一列是一張單據還沒結清的那一邊,差額標示「待付」「待退」「待收」。按該列的按鈕(付款、收到退款、收款、退款)會打開付款視窗,金額已經先填好剛好結清的數字,可以改。
- **關帳**:在「關帳」分頁,每個月一列,顯示進行中、未關帳或已關帳,以及關帳時間與關帳人。「關帳」按鈕只出現在最早一個還沒關帳、而且已經結束的月份。按下後先看檢查清單與快照預覽(每個帳戶月底餘額、每家分店小金庫與抽屜、沒有被日結涵蓋計算的班),在下方輸入同一個月份(例 2026-09)再按「關帳」。已關帳的月份按「快照」可以看關帳當下的數字。

## 重要規則

- **有交易之後,期初餘額與期初日期就不能改**;銀行代碼、帳號、戶名、分行、使用組織隨時可以改。
- **沒有任何交易的帳戶才能刪除**;有交易的帳戶只能停用。停用的帳戶不能再登記交易,付款時也選不到。
- 餘額是隨時算出來的;**變成負數只會以警示色提醒**,不會擋下。
- 交易與現金流水**只能新增**,記錯一律用沖正,不能修改或刪除;同一筆只能沖正一次。
- 小金庫應有的金額**完全由流水加總**:從最近一次日結的清點金額起算,還沒有日結時從 0 起算。
- 付款視窗選「現金」時,經手人 / 收款人一定要填;從收銀點抽屜付現,那個收銀點要有開著的班。
- 「兌獎入帳」不算進任何單據的已付或已收。
- **關帳是全部分店一起關**,要**依月份順序**,而且只能關已經結束的月份;關到那個月的最後一刻(10/31 晚上 11:59 的紀錄算 10 月)。
- 那個月還有收銀班次沒交班結帳,或還有撤銷售出申請、現金更正單、結帳確認申請在審核中、而且會記到那個月,就**不能關帳**,要先處理完。有班沒有被日結涵蓋計算只會提醒,並記在快照裡。
- **關帳後不能重新開帳**。上個月的錯誤請用原本的功能**在現在更正**(銀行沖正再登記一筆、現金更正單、撤銷售出申請、尋回、報廢),報表會把它們歸在「前期更正」。
- 撤銷售出申請的退款班次、現金更正單的位置**不能選已關帳月份的班**,開班或改對應排班時選的排班也**不能是已關帳月份的排班**;現金更正單的「歸屬班次」可以選(只表示是誰的責任)。
- 每月 3 號 09:00 如果上個月還沒關帳,有關帳權限的人會收到「關帳逾期」提醒(時間可以在通知設定調整)。
- **看得到的按鈕就是你做得了的事**:沒有「+ 新增帳戶」「登記交易」「沖正」、付款或「關帳」按鈕,代表你沒有那個權限,需要時請洽系統管理員。
