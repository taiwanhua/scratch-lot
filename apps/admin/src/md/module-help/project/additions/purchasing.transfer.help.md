# 調貨單

## 這個模組做什麼

把刮刮樂從一家分店**調**到另一家分店:可以整本調,也可以從拆過的本挑幾張調(**選張**)。出貨分店確認出貨後,刮刮樂變成**在途**;送到收貨分店,由收貨分店店長**點收**(整本的刷一張、選張的逐張點收),點收後才進到收貨分店的庫存。調貨單也記兩家分店之間的**結算**(收貨分店付款、出貨分店收款)。

收貨分店不發起調貨單;缺貨時請開叫貨單,由總部安排從其他分店調貨。

## 側欄數字

側欄「調貨單」旁的數字,是**等你點收的調貨單數**:收貨分店點收這一關(第二關)在你手上、還沒點收完成的調貨單;還在出貨確認的不算。

- **找出是哪幾張**:在申請中心的「待我審核」(待處理)可以看到這些調貨單,打開就能點收。
- 滑鼠移到數字上(手機、平板請長按數字)會顯示這個數字算的是什麼。沒有就不顯示,超過 99 顯示「99+」。
- 全部點收並核准後,這張就不再算。

## 常用操作

- **新增調貨單**:按 [+ 新增調貨單],選出貨分店、收貨分店(不能相同),需要時選收貨分店待購買的叫貨單。在右邊選一本:沒拆過的本按 [整本加入](拆過又全部收回的本也算拆過,只能選張);拆過的本在張數格子點選要調的張(可以用「連號快選」或按住 Shift 連選),再按 [加入選取]。也可以刷條碼:刷到沒拆過的本直接整本加入,刷到拆過的本會選起那一張。按 [送出];還沒選完可以先按 [存草稿]。
- **修改草稿或被退回的單**:按 [編輯] 會打開和新增時一樣的畫面,帶入原本的內容。已點收的本標「已點收」,不能改也不能移除;已出貨、還在路上的本標「在途」,不能改(批購金額率也不能改),路上遺失時可以整列移除(送出後變待查);選張的列只到了部分張時(標「部分點收 9 / 12」),按 [移除沒到的張] 展開格子,取消勾選沒到的張(已點收的張不能動),送出前會再確認「054、055、056 這 3 張會變成待查」;還沒出貨的本可以改、移除,也可以再加新的本。有已出貨或已點收的本時不能換出貨分店或收貨分店。
- **刷條碼**:刷背面編號會自動認出遊戲;刷正面條碼時,如果出貨分店有兩款以上的遊戲用同一個本號,請先選「正面條碼的遊戲」。點收時遇到同一個本號有好幾款遊戲,會先擋下並出現「正面條碼的遊戲」選單,選好就照你選的遊戲點收。
- **從叫貨單帶入**:在叫貨、採購單的採購清單按 [從其他分店調貨],會帶入那張叫貨單與收貨分店。
- **批購金額率**:預設是這一本的成本率,可以逐本改。金額:整本 = 整本金額;選張 = 面額 × 張數。批購金額 = 金額 × 批購金額率;調貨金額 = 批購金額合計。
- **出貨確認(第一關)**:出貨分店店長在申請中心打開調貨單,核對出貨確認清單後核准,刮刮樂就變成在途,收貨分店會收到「調貨出貨通知」,點通知會打開這張調貨單。出貨分店的人自己送出的調貨單會直接跳過這一關。
- **點收(第二關)**:收貨分店店長在「點收」區塊點收(從申請中心或通知打開、或在調貨單打開都可以)。**整本的列**刷這本的任何一張,整本一起點收。**選張的列逐張點收**:刷背面編號點收刷到的那一張(那一列會自動展開張數格子、捲到並閃一下;同一張再刷會提示「這張已經點收」);也可以按 [展開格子] 點選已經到的張再按 [點收選取的 N 張];全部都到了就按 [其餘全部到齊…],確認後一次點收剩下的張。每一列顯示「未點收 0 / 10」「部分點收 9 / 12」「已點收」;每組標題會顯示單上本數與已點收幾本(一列全部到齊才算 1 本),例「已刷 4,已點收 2 / 4」。可以分次點收,這一批點收完按 [完成這次點收]。
- **調貨點收單**:按 [完成這次點收] 時自動印調貨點收單兩聯:第 1 聯 收貨店留存、第 2 聯 送貨人留存,上面列這次點收的刮刮樂(整本寫本號,選張寫這次點收的號碼區段)與尚未到的本(選張的列只到部分張時,寫還沒到的號碼),請點收人與送貨人簽名。每按一次 [完成這次點收] 就是一張調貨點收單(單上印「第幾次點收」);點收過兩次以上時,補印前先在「點收批次」選要補印哪一次。
- **調貨出貨單**:出貨確認通過時(不論在調貨單或申請中心核准;出貨分店的人自己送出、直接跳過這一關也算),自動印調貨出貨單兩聯:第 1 聯 出貨店留存、第 2 聯 送貨人留存,只列這次出貨的刮刮樂(退回修改後再送出時,之前已經出貨的不會再印;沒有新出貨的就不印),請出貨人、送貨人簽名。在調貨單上方按 [列印] 也可以再印。
- **調貨付款收據**:收貨分店按 [付款] 選現金,記好之後自動印調貨付款收據兩聯:第 1 聯 收貨店留存、第 2 聯 送貨人留存,請付款人簽名、送貨人簽收。在調貨單上方按 [列印] 會印最近一筆現金付款的收據。
- **兩聯與補印**:這三種單據都是一次印出兩聯(兩聯中間切開,算印 1 次),每聯標題下方印聯別。還沒印過時自己按 [列印],可以先選要印哪一聯(兩聯都印、第 1 聯、第 2 聯);只印第 1 聯也算印了第 1 次,之後要印第 2 聯請按 [補印]。印過的單據按 [補印] 時,可以選要補哪一聯(兩聯都補、第 1 聯、第 2 聯,預設兩聯都補)再選補印原因;補印的每一聯上方印「【補印】第幾次」、時間、原因與補印人。次數以「次」計:原來那一次是第 1 次,第一次補印是第 2 次。
- **列表**:顯示單號、出貨分店、收貨分店、調貨金額、本數 / 張數、點收進度、結算(待付 / 待退 / 待收)與狀態;已出貨還沒點收完的顯示「在途」。可以依狀態篩選(包含草稿)。
- **結算**:檢視頁的「結算」區塊列出調貨金額、收貨店已付、出貨店已收與待收,以及每一筆收付紀錄。收貨分店按 [付款] [收到退款](可以付現或轉帳;從小金庫付現時金額不能超過小金庫目前應有的錢,不夠時先用現金更正單登記小金庫實際的錢);出貨分店按 [收款] [退款](一律銀行)。收貨店已付比出貨店已收多時,會提示「N 待出貨店入帳」。

## 重要規則

- **總部替分店建的單**:總部建的調貨單,看得到出貨分店或收貨分店的人(兩邊分店的人、看得到它們的上層組織的人)都看得到,但只能看、不能修改或刪除;每一邊的收付仍只有那一邊的分店能記。草稿只有建立的人看得到。
- **送出後就鎖住(調貨中)**:單上的刮刮樂不能賣,也不能放到別張調貨單上;送出前會檢查每一本、每一張都在出貨分店、還沒賣出。
- **超過預計要給本數只提醒**:收貨分店已給 + 在途 + 這次整本調過去的本數超過預計要給本數時,新增頁會列出超過的遊戲,照樣可以送出。
- **選不到收貨分店時**:調貨由總部開單;要自己開,請管理員把你加入收貨分店。
- **只有拆過的本能選張**,而且要有零碎張數的權限;沒拆過的本只能整本調。
- **按鈕先填的金額就是「這一邊按下去剛好結清」的金額**;算出來是 0 時那顆按鈕不能按。收貨分店的 [付款] 照**已點收**的批購金額算(選張的列只到部分張時,照到的張數算);出貨分店只有在已收少於調貨金額時才能按 [收款]。
- **少張怎麼辦**:有張沒到時不能核准,畫面會提示「還有 3 張沒點收(100002 #054–056),請退回由出貨店移除沒到的張」。請按 [退回];出貨分店在編輯畫面取消勾選沒到的張再送出,那幾張變成待查(責任分店是出貨分店),調貨金額照實際到的張數重算;再由收貨分店核准。
- **核准前三個數字要相等**:全部點收,而且收貨店已付 = 出貨店已收 = 調貨金額;不相等時會擋下,並提示哪一邊還沒記(例「出貨店還沒記收款」「出貨店多收,請先記退款」)。
- **退回或撤回**:還沒出貨的刮刮樂解除鎖定;已在途的保持在途;結算紀錄保留。
- **路上遺失**:退回後把在途的那一列刪掉再送出,那幾張會變成待查,責任分店是出貨分店。
- **已點收的列不能改或刪**(部分點收的列只能移除還沒點收的張);已經點收過的調貨單不能駁回或刪除。
- **刪除草稿**:只有草稿可以刪除(自己的草稿,列表與調貨單上方會有 [刪除]),刪除前會再確認一次。已經送出的單(包含被退回、撤回的)不能刪除,不要的話請作廢或駁回。
- **送錯分店**:刷到送往別家分店的本會擋下,不會入庫,畫面會告訴你這本屬於送往哪一家分店的哪一張調貨單,請交給送貨人帶過去。[知道了] 不會記錄任何東西;如果是單子寫錯(這本其實是給你這家店的),按 [通知總部更正],這張調貨單的建立者會收到通知。
- **駁回或作廢**:全部回到出貨分店,叫貨單回到待購買。作廢要填作廢原因;調入後已經賣出、再調出或拆本的不能作廢。駁回或作廢前,兩邊的結算都要先歸零(人工記的帳請沖正)。
- **草稿不算數**:草稿只有自己看得到,不鎖刮刮樂、不算在途。
- **誰點收**:收貨分店的「店長」。等著點收的調貨單會算在側欄「調貨單」的數字裡;還在出貨確認的不算。
- **列印**:單據遺失或破損時按 [補印],選補印原因後送出,補印的單據上方會印「【補印】第幾次」、時間、原因與補印人。這家店沒有設定印表機時 [列印] 是灰的;沒有列印權限時不會出現 [列印],也不會自動列印。
- 沒有收貨店付款的權限時看不到收貨分店的 [付款] [收到退款];沒有出貨店收款的權限時看不到出貨分店的 [收款] [退款];沒有新增的權限時看不到 [+ 新增調貨單]。
