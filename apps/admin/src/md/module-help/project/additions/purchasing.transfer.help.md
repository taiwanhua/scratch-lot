# 調貨單

## 這個模組做什麼

把刮刮樂從一家分店**調**到另一家分店:可以整本調,也可以從拆過的本挑幾張調(**選張**)。出貨分店確認出貨後,刮刮樂變成**在途**;送到收貨分店,由收貨分店店長**逐本刷條碼點收**,點收後才進到收貨分店的庫存。調貨單也記兩家分店之間的**結算**(收貨分店付款、出貨分店收款)。

收貨分店不發起調貨單;缺貨時請開叫貨單,由總部安排從其他分店調貨。

## 常用操作

- **新增調貨單**:按 [+ 新增調貨單],選出貨分店、收貨分店(不能相同),需要時選收貨分店待購買的叫貨單。在右邊選一本:沒拆過的本按 [整本加入];拆過的本在張數格子點選要調的張(可以用「連號快選」或按住 Shift 連選),再按 [加入選取]。也可以刷條碼:刷到沒拆過的本直接整本加入,刷到拆過的本會選起那一張。按 [送出];還沒選完可以先按 [存草稿]。
- **從叫貨單帶入**:在叫貨、採購單的採購清單按 [從其他分店調貨],會帶入那張叫貨單與收貨分店。
- **批購金額率**:預設是這一本的成本率,可以逐本改。金額:整本 = 整本金額;選張 = 面額 × 張數。批購金額 = 金額 × 批購金額率;調貨金額 = 批購金額合計。
- **出貨確認(第一關)**:出貨分店店長在申請中心打開調貨單,核對出貨確認清單後核准,刮刮樂就變成在途,收貨分店會收到「調貨出貨通知」。出貨分店的人自己送出的調貨單會直接跳過這一關。
- **點收(第二關)**:收貨分店店長在「點收」區塊逐列刷條碼(刷這一列的任何一張)。可以分次點收,刷完這一批按 [完成這次點收]。
- **調貨出貨單**:出貨確認通過時(不論在調貨單或申請中心核准;出貨分店的人自己送出、直接跳過這一關也算),自動印一張調貨出貨單,只列這次出貨的刮刮樂(退回修改後再送出時,之前已經出貨的不會再印;沒有新出貨的就不印),請出貨人、送貨人、收貨人簽名。在調貨單上方按 [列印] 也可以再印。
- **調貨付款收據**:收貨分店按 [付款] 選現金,記好之後自動印一張調貨付款收據,請送貨人簽收。在調貨單上方按 [列印] 會印最近一筆現金付款的收據。
- **列表**:顯示單號、出貨分店、收貨分店、調貨金額、本數 / 張數、點收進度、結算(待付 / 待退 / 待收)與狀態;已出貨還沒點收完的顯示「在途」。可以依狀態篩選(包含草稿)。
- **結算**:檢視頁的「結算」區塊列出調貨金額、收貨店已付、出貨店已收與待收,以及每一筆收付紀錄。收貨分店按 [付款] [收到退款](可以付現或轉帳);出貨分店按 [收款] [退款](一律銀行)。收貨店已付比出貨店已收多時,會提示「N 待出貨店入帳」。

## 重要規則

- **總部替分店建的單**:總部建的調貨單,出貨分店與收貨分店的人都看得到,但只能看、不能修改或刪除;每一邊的收付仍只有那一邊的分店能記。草稿只有建立的人看得到。
- **送出後就鎖住(調貨中)**:單上的刮刮樂不能賣,也不能放到別張調貨單上;送出前會檢查每一本、每一張都在出貨分店、還沒賣出。
- **超過預計要給本數只提醒**:收貨分店已給 + 在途 + 這次整本調過去的本數超過預計要給本數時,新增頁會列出超過的遊戲,照樣可以送出。
- **選不到收貨分店時**:調貨由總部開單;要自己開,請管理員把你加入收貨分店。
- **只有拆過的本能選張**,而且要有零碎張數的權限;沒拆過的本只能整本調。
- **按鈕先填的金額就是「這一邊按下去剛好結清」的金額**;算出來是 0 時那顆按鈕不能按。收貨分店的 [付款] 照**已點收**的批購金額算;出貨分店只有在已收少於調貨金額時才能按 [收款]。
- **核准前三個數字要相等**:全部點收,而且收貨店已付 = 出貨店已收 = 調貨金額;不相等時會擋下,並提示哪一邊還沒記(例「出貨店還沒記收款」「出貨店多收,請先記退款」)。
- **退回或撤回**:還沒出貨的刮刮樂解除鎖定;已在途的保持在途;結算紀錄保留。
- **路上遺失**:退回後把在途的那一列刪掉再送出,那幾張會變成待查,責任分店是出貨分店。
- **已點收的列不能改或刪**;已經點收過的調貨單不能駁回或刪除。
- **送錯分店**:刷到送往別家分店的本會擋下,不會入庫,畫面會告訴你這本屬於送往哪一家分店的哪一張調貨單,請交給送貨人帶過去。[知道了] 不會記錄任何東西;如果是單子寫錯(這本其實是給你這家店的),按 [通知總部更正],這張調貨單的建立者會收到通知。
- **駁回或作廢**:全部回到出貨分店,叫貨單回到待購買。作廢要填作廢原因;調入後已經賣出、再調出或拆本的不能作廢。駁回或作廢前,兩邊的結算都要先歸零(人工記的帳請沖正)。
- **草稿不算數**:草稿只有自己看得到,不鎖刮刮樂、不算在途。
- **誰點收**:收貨分店的「店長」。等著點收的調貨單會算在側欄「調貨單」的數字裡;還在出貨確認的不算。
- **列印**:單據遺失或破損時按 [補印],選補印原因後送出,補印的單據上方會印「【補印】第幾次」、時間、原因與補印人。這家店沒有設定印表機時 [列印] 是灰的;沒有列印權限時不會出現 [列印],也不會自動列印。
- 沒有收貨店付款的權限時看不到收貨分店的 [付款] [收到退款];沒有出貨店收款的權限時看不到出貨分店的 [收款] [退款];沒有新增的權限時看不到 [+ 新增調貨單]。
