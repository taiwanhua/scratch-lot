# 出勤紀錄

## 這個模組做什麼

看打卡與出勤紀錄(依人員看一個月、依分店看一天),以及申請補打卡。

## 常用操作

- **依人員(月)**:選人員與月份,看每一天的班、上班 / 下班打卡、實際工時、遲到、早退與特殊日。缺卡的班旁邊有 [補打卡],會帶入那一班。
- **依分店(日)**:選分店與日期,看當天排班的人是否已到、上下班打卡、遲到 / 早退;上方寫「排班 4 人 · 已到 3 · 未到 1 · 未對應排班的打卡 2 張」。勾「只看未對應排班的打卡」只看沒有對應到排班的卡。
- **補打卡申請**:按 [補打卡申請](或某一班的 [補打卡]、我的班表的 [申請補卡]),填補打卡時間(日期與時間)、分店、**對應排班**、類型(上班 / 下班)與原因後 [送出]。選了補打卡時間與分店後,「對應排班」會列出你那天在那家店的班(包括前一天做到這天的跨午夜的班),最後一個是「沒有排班(臨時代班)」;改了日期或分店要重新選,同一天只改時間不用。跨午夜的班補下班卡,直接選隔天的時間(例 22:00–02:00 的班,選隔天 02:10)。從某一班的 [補打卡] 進來會先帶入那張卡排定的時間,請改成實際的時間。
- **改對應排班**:打卡對到錯的班,或臨時代班補排班後,按那一列的 [改對應排班],選要對應的排班(或「沒有排班」)與原因後儲存。
- **匯出 Excel**:按 [匯出 Excel],這個月的出勤紀錄一家分店一個工作表:日期、人員、排班、上班、下班、在班時數、休息、實際工時、排班工時、遲到、早退、特殊日類別、補卡註記。

## 重要規則

- **總部替分店建的單**:總部替分店建的補打卡申請,看得到單上分店的人(該分店的人、看得到該分店的上層組織的人)也看得到,但只能看、不能修改或刪除;草稿只有建立的人看得到。
- 沒有「看全部」的權限時只看得到自己的出勤紀錄。
- 打卡的時間與類型不能改;忘記打卡請申請補打卡,由店長審核。
- **遲到 / 早退**:超過分店的寬限(排班設定 → 規則「遲到 / 早退寬限」,預設 5 分鐘)才算;晚了剛好 5 分鐘不算,5 分 1 秒就算。超過寬限時以整分鐘無條件進位(晚 5 分 1 秒記「遲到 6 分」)。
- **未對應排班的打卡**:沒有對應到排班的卡另列在「未對應排班」。可以在這裡按 [改對應排班],或到排班作業的班表格子(右上角時鐘圖示)打開排班對話框勾選對應;月檢視的 ⏲ 標出哪幾天有這種卡。
- **實際工時** = 下班 − 上班 − 休息;只有一張卡時不算。這裡不做薪資計算。
- 出勤紀錄不會自動更新;要看最新的打卡請重新打開這一頁。
- **補打卡申請沒有草稿**,送出後就進入審核;**對應排班一定要選**。核准後會新增一張補打卡,記在你選的那一班(選「沒有排班」就是未對應排班的卡)。
- 審核中如果你選的那一班被刪除,店長不能核准,只能退回讓你重選;那一班只改了時間的話照常核准。
- **改對應排班一定要選原因**(「改對應排班原因」,選「其他」要填說明),修改會留下紀錄;沒有這個權限時看不到 [改對應排班]。
