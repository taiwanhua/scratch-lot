# 檔案管理

## 這個模組做什麼

維護刮刮樂的兩份基本資料:**遊戲**(每一款刮刮樂)與**收銀點**(分店內收錢的位置)。上方的分頁切換兩者;只看得到其中一種時不會出現分頁。

遊戲由最上層組織統一維護,每家分店看到的是同一份;收銀點屬於各分店,只看得到自己看得到的分店的收銀點。

## 常用操作

- **找遊戲**:用「狀態」「面額」篩選,或在「關鍵字」輸入代號或名稱。預設只列販售中的遊戲,要看停售的請把狀態改成「停售」或「全部」。
- **新增遊戲**:按右上的「+ 新增遊戲」。遊戲代號是 4 碼數字,不能和其他遊戲重複。單張金額可從 100、200、300、500、1,000、2,000 選,也可以自己輸入,但一定要是 100 的倍數(輸入其他數字時欄位下方會提示);選了預設面額會自動帶入整本張數(100 / 100 / 100 / 50 / 25 / 18 張),可以再改。整本金額由系統算好。兌獎截止日必填;上市日與停售日由兌獎截止日自動算出(停售日 = 兌獎截止日往前 3 個月、上市日 = 往前 9 個月,那個月沒有同一天就用月底),不能自己改。停售日只是記錄,到了不會自動改成停售。
- **看遊戲**:點列表上的一列進入遊戲詳情;有編輯權限時右上有「編輯」。
- **顏色**:只能從色票選,用在店面看板的卡片上。
- **停售**:把狀態改成「停售」。停售的遊戲不能再出現在新的叫貨單與進貨單,調貨、銷售、盤點照常。
- **新增收銀點**:切到「收銀點」分頁按「+ 新增收銀點」,選分店與對應崗位;選了崗位會自動帶入崗位名稱當收銀點名稱,可以再改。崗位清單找不到要的那一個時,選單下方有「找不到?到欄位管理新增」(要有欄位管理的權限才看得到)。
- **編輯收銀點**:按該列的「編輯」,可以改崗位、名稱、排序、印表機、啟用狀態與備註。印表機不選就是用分店的預設印表機。

## 重要規則

- **有庫存的遊戲**(已經有本、或被叫貨單、進貨單用過)不能改代號、單張金額、整本張數,也不能刪除,只能停售。編輯頁上方會提示。
- 只有**從來沒被用過**的遊戲才看得到「刪除」;刪除後無法復原。
- 面額與張數不是標準組合時只會提示,照樣可以存。
- **收銀點不能刪除**,不用了就停用。有開著的班或檯面上還有刮刮樂時不能停用。
- 同一家分店裡,收銀點的對應崗位不能重複,名稱也不能重複;建立後不能換分店。
- **看得到的按鈕就是你做得了的事**:沒有「+ 新增遊戲」「編輯」「刪除」「+ 新增收銀點」,代表你沒有那個權限,需要時請洽系統管理員。
