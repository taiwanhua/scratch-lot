# 庫存管理

## 這個模組做什麼

看每一本刮刮樂現在在哪裡、還剩幾張、發生過什麼事。上方三個分頁:**庫存**(以本為單位的列表)、**待查·遺失**(找不到的刮刮樂)、**預計要給本數**(每家分店每個遊戲預計要給幾本、已經給了幾本)。右上的「查刮刮樂」可以刷條碼或輸入編號,直接找到那一張。

## 常用操作

- **看庫存**:在「庫存」分頁先選分店(預設是你目前所在的組織),再用遊戲、狀態(未拆、檯面中、售完、有待標註)、批購日、本號篩選。一本拆到兩家店時,所在分店會顯示「台北 70 / 新竹 30」。點一列進入本的詳情。
- **查刮刮樂**:按「查刮刮樂」,用條碼槍刷條碼,或輸入背面編號(例:5164-1-056527-071-0-6),也可以輸入正面編號或正面條碼。找到後按「查詢」,會打開那一本並把那一張選起來。
- **本的詳情**:上方是來源(進貨單或調貨單)、所在(還沒賣的張在哪家店、哪個收銀點)與成本;中間是張數格子,下方是事件時間軸(進貨、拆本、移櫃、售出、跳號、待查、尋回、報廢……,誰、什麼時間、從哪裡到哪裡)。
- **報廢**:破損、污損、受潮的刮刮樂,在格子上選那幾張(只能選未售的),格子上方會出現操作列,按「報廢」並選報廢原因。
- **尋回**:找到待查或遺失的刮刮樂時,在格子上選那幾張按「尋回」並選尋回原因,刮刮樂會回到**它原本所在那家店**的庫存(不會換店;例:總部替中山店尋回,還是回到中山店)。整本都待查時,頁首會出現「整本尋回」。在「待查·遺失」分頁也可以直接按「尋回」。在店面刷到待查或遺失的刮刮樂時,會回到刷到的那家店。
- **更正跳號**:拆本時跳號標錯了,在本的詳情頁首按「更正跳號」。格子會先選好目前的跳號,改成正確的張號後選更正原因;改完的張數要等於待標註的張數。時間軸會留下「取消跳號」與「跳號」兩筆紀錄。
- **預計要給本數**:每一格是「已給 / 預計」。可以修改時,點格子填新的預計本數(可以加備註)。遊戲詳情、乙類詳情的「預計要給本數」分頁是同一份資料。

## 重要規則

- **已給本數** = 進貨 + 調入 − 調出,賣掉不扣;一本在這家店的張數不滿一整本時顯示「+N 張」,零碎的張數不會湊成一本。已給超過預計時以警示色提醒,不會擋下;叫貨單、進貨單、調貨單也只提醒。
- 只要分店持有某一本的任何一張,就看得到那一本的詳情;但**只能操作你看得到的分店的張**。其他分店的張在格子上是灰色的「其他分店」,不能選。一本分在幾家店時,把游標移到格子上(手機長按)可以看到那一張在哪家店。
- 報廢只能報**未售**的張;報表以批購成本計算報廢的損失。
- 原因選「其他」時一定要填說明。
- 待查的張要在盤點確認申請裡才能「確認遺失」(店面管理)。
- **看得到的按鈕就是你做得了的事**:沒有「更正跳號」「報廢」「尋回」、看不到成本,或預計要給本數不能點,代表你沒有那個權限,需要時請洽系統管理員。
