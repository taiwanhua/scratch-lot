# 輸出報表

## 這個模組做什麼

選一張報表,設定期間與分店,先在畫面上預覽,或直接匯出成 Excel。

畫面左邊是「報表」選單,只列出你有權限的報表;右邊是那張報表的條件。

## 常用操作

- **選期間**:
  - **日**:選一個日期,或按 [今天] [昨天]。
  - **週**:在月曆上點任一天,就會選到那一整週(一週從星期日開始),下方顯示這週的起訖,例如「10/11(日)~ 10/17(六)」;也可以按 [本週] [上週]。
  - **月**:點月份格子,或按 [本月] [上月];用左右箭頭換年份。
- **選分店**:可以選多家,每張報表有家數上限(寫在報表名稱後面),到了上限就不能再勾。
- **預覽**:按 [預覽] 在畫面上看報表。上方的頁籤可以切換「全部分店合計」與各分店,一開始顯示合計。按 [返回條件] 回去改條件。
- **匯出 Excel**:按 [匯出 Excel] 下載。檔案裡每家分店一個工作表,再加一個「全部分店合計」;已設定好 A4、一頁寬、每頁重複標題列,直接列印即可。

## 重要規則

- 期間都以本公司所在地的日期計算,與你電腦的時區無關。週一律從星期日開始;沒有自訂起訖。
- 沒有選分店時不能預覽或匯出。
- 期間或分店數超過報表的上限時,會提示你縮小範圍。
- 選單是空的,代表你目前沒有任何報表的權限;看不到 [匯出 Excel],代表你沒有匯出的權限。需要的話請洽系統管理員。
- 改了條件之後要重新按 [預覽],畫面才會換成新的結果。

## 營運報表

一家店一份,分 8 個區塊:銷售、毛利、兌獎、庫存異動、現金、銀行、未結清、註記;最後再依遊戲列出銷售。上方的頁籤切換「全部分店合計」與各分店。

- **銷售**:刷條碼售出、手動標記(依原因分開列)、盤點補登、撤銷,以及淨銷售(售出扣掉撤銷)。
- **毛利**:已售出的刮刮樂的成本合計與毛利。沒有「成本與毛利」權限的人看不到毛利,成本欄也是空的。
- **兌獎**:只算有效的兌獎;被撤銷的另外列一行。
- **庫存異動**:進貨、調入、調出、調貨損益(調貨金額扣掉原本的成本)、報廢、遺失、尋回、跳號(不算成本)、期末庫存與待查。調貨單作廢時,調入 / 調出在作廢那天的報表扣回來。
- **現金**:各班結帳的差額合計、事後更正(依原因分開列)、退貨退款、調貨的現金收付、投庫、存銀行、日結的小金庫差異。
- **銀行**:這家店用的帳戶,只算歸屬這家店的交易;期末餘額是整個帳戶的,共用的帳戶會註明。
- **未結清**:期末那一刻還沒付清 / 收齊的批貨款與調貨款(期末之後才付的,不影響這份報表)。
- **註記**:跳過盤點的次數與原因、盤點沒盤完的本數(「N 本未盤」)、還沒被日結算進去的班、前期更正、尚未關帳的月份。

### 對齊日結

選「日」時可以勾「對齊日結」:每家店改用「上一次日結到當天日結」的時間(同一天有好幾次日結,就從最早那次的起點算到最後一次),下方會逐店列出實際期間。當天沒有日結的店改用整天,並註明「未日結,期間改用整天,小金庫和盤點未核對」。

- 不要把多天的日報加起來當週報或月報;要看一週請直接選「週」。

### 已關帳的月份

選「月」時,月份下方會標示「已關帳」或「尚未關帳」。已關帳的月份數字固定;之後才更正的,會列在更正當時那份報表的「前期更正」。

## 班次結帳歷史報表

一班一列:日期、收銀點、負責人、協同、任務內容、開班與結帳時間、應有、實點、差額、原因、之後的更正、盤點、審核狀態。

- 可以只看某個收銀點(選了好幾家店時,選項前面會寫分店名),或勾「只看有差額」。
- 「盤點」欄:交班時跳過盤點的會一直標示「未盤點(跳過)」與原因;盤點沒盤完的標示「N 本未盤」。
- 「之後的更正」列出那一班交班之後才補記的更正(例如店長撤銷並重新登記兌獎),寫明金額、日期與類型,說明當時的差額為什麼不是 0。這一班的應有、差額仍是結帳當時的數字;關帳之後才記的會註明「前期更正」。
