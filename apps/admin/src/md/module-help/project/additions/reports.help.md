# 輸出報表

## 這個模組做什麼

選一張報表,設定期間與分店,先在畫面上預覽,或直接匯出成 Excel。

畫面左邊是「報表」選單,只列出你有權限的報表;右邊是那張報表的條件。

## 常用操作

- **選期間**:
  - **日**:選一個日期,或按 [今天] [昨天]。
  - **週**:在月曆上點任一天,就會選到那一整週(一週從星期日開始),下方顯示這週的起訖,例如「10/11(日)~ 10/17(六)」;也可以按 [本週] [上週]。
  - **月**:點月份格子,或按 [本月] [上月];用左右箭頭換年份。
- **選分店**:可以選多家,每張報表有家數上限(寫在報表名稱後面),到了上限就不能再勾。
- **預覽**:按 [預覽] 在畫面上看報表,內容和匯出的 Excel 一樣。上方的頁籤可以切換「全部分店合計」與各分店,一開始顯示合計。用手機看時,表格的每一列會變成一張卡片。按 [返回條件] 回去改條件。
- **匯出 Excel**:按 [匯出 Excel] 下載。檔案裡每家分店一個工作表,再加一個「全部分店合計」;已設定好 A4、一頁寬、每頁重複最上面的說明列,直接列印即可。

## 重要規則

- 期間都以本公司所在地的日期計算,與你電腦的時區無關。週一律從星期日開始;沒有自訂起訖。
- 沒有選分店時不能預覽或匯出。
- 期間或分店數超過報表的上限時,會提示你縮小範圍。
- 選單是空的,代表你目前沒有任何報表的權限;看不到 [匯出 Excel],代表你沒有匯出的權限。需要的話請洽系統管理員。
- 改了條件之後要重新按 [預覽],畫面才會換成新的結果。

## 營運報表

一家店一份,每個區塊一張小表。最上面三列寫報表名稱、分店、期間、是否已關帳、產出時間和產出人;負數用紅字。選了兩家以上的分店,最後會多一頁「分店比較」,把各店的重要數字排在一起。

**每個數字都是期間結束那一刻的狀況**:之後才撤銷的兌獎、之後才調走的張、之後才補的日結,都算在發生那天的報表,所以同一段期間的報表重新產生,數字不會變。

- **1 銷售**:這段期間賣了多少。刷條碼售出、手動標記(依原因分開列)、補登售出、撤銷(負數,可能是以前賣出的),最後是淨銷售。下面的「依遊戲」把每款遊戲的售出、撤銷、淨張數與金額分開列。
- **2 毛利**:賣出的這些張賺了多少價差。成本用賣出當下記下的成本,之後調走、成本變了也不影響;毛利率 = 毛利 ÷ 淨銷售金額。沒有「成本與毛利」權限的人看不到這一塊。
- **3 兌獎**:這段期間登記的兌獎,看期間結束那一刻的狀態。兌獎(有效)= 其中店內持有 + 其中已送兌,含不是本店賣出的中獎券;期間結束前已撤銷的另外列一行。
- **4 庫存異動**:由上往下加減,最後一列「核對」要是 0。期初庫存加上進貨、調入、待查轉回、遺失尋回,扣掉調出、淨銷售、報廢、新增待查,再加減成本調整,等於期末庫存;不是 0 表示有資料需要查。調出看的是出貨的時間(張變成在途那一刻);調貨單作廢時,在作廢那天扣回來。「成本調整」只有成本、張數不變:調貨單少收幾張、出貨店重送後,已點收的張成本改成縮小後的批購金額,差額算在重送那天。
- **4 · 另外列的**:不在上面加減裡、列出來對照的:期末在途(已出貨、對方還沒點收)、期末待查、確認遺失(新增待查時已扣過庫存)、跳號(實際不存在的張號,不算成本)、調貨損益(調出的調貨金額扣掉原本的成本)。
- **還沒標的跳號**:一本的迄號比標準張數多出來、拆本前還沒標的跳號,實際不存在,不算庫存張數與成本;所以進貨、整本調貨、整本找不到時,都以標準張數計算。
- **5a 差額與更正**:+ 是錢比帳多、− 是錢比帳少。各班結帳差額(只算期間結束時待審核或已核准的,被退回還沒重送的不算)、事後更正(補記到已結帳的班;那一班真正的差額 = 當時的結帳差額 − 事後更正)、日結的小金庫差額。
- **5b 現金移動**:+ 是錢進來、− 是錢出去,分「抽屜」「小金庫」兩欄:投庫、出庫、存銀行、退貨退款(班開著時)、調貨的現金收付、現金更正。賣出收的錢與兌獎付的錢不在這裡;要看抽屜和小金庫完整的應有,請看帳戶管理的即時現金帳。
- **6 銀行**:這家店用的帳戶,只算歸屬這家店的交易;同一種類型合成一列(收、支、淨額),沖正的也算在同一列並註明筆數。期末餘額是整個帳戶的,共用的帳戶會註明。
- **7 未結清**:期間結束那一刻還沒付清 / 收齊的進貨款與調貨款(包含調貨多付、多收要退的),每種列出單數與單號(最多 5 張)。期間結束之後才付的,不影響這份報表。
- **8 註記**:跳過盤點的次數與原因、盤點沒盤完的本數(「N 本未盤,共 N 次盤點」)、到期間結束時還沒被日結算進去的班、前期更正、尚未關帳的月份。

### 對齊日結

選「日」時可以勾「對齊日結」:每家店改用「上一次日結到當天日結」的時間(同一天有好幾次日結,就從最早那次的起點算到最後一次),下方會逐店列出實際期間。當天沒有日結的店改用整天,並註明「未日結,期間改用整天,小金庫和盤點未核對」。

- 不要把多天的日報加起來當週報或月報;要看一週請直接選「週」。

### 已關帳的月份

選「月」時,月份下方會標示「已關帳」或「尚未關帳」。已關帳的月份數字固定;之後才更正的,會列在更正當時那份報表的「前期更正」。

## 班次結帳歷史報表

一班一列:日期、收銀點、負責人、協同、任務內容、開班與結帳時間、應有、實點、差額、原因、事後更正、盤點、審核狀態。

- 可以只看某個收銀點(選了好幾家店時,選項前面會寫分店名),或勾「只看有差額」。
- 「盤點」欄:交班時跳過盤點的會一直標示「未盤點(跳過)」與原因;盤點沒盤完的標示「N 本未盤」。
- 「事後更正」列出那一班交班之後才補記的更正(例如店長撤銷並重新登記兌獎),寫明金額、日期與類型,說明當時的差額為什麼不是 0。這一班的應有、差額仍是結帳當時的數字;關帳之後才記的會註明「前期更正」。
