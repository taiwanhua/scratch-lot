# 批售單

## 這個模組做什麼

分店把**未拆的整本**刮刮樂賣給批售客戶(向我們買整本的其他彩券行),這張單據叫**批售單**。送出後單上的本就鎖住(**批售中**),由出貨分店的店長**出貨確認**;核准就是出貨,單據完成,這些本變成**已批售**、不再算在任何一家店的庫存。

批售客戶在「經銷商管理」的「批售客戶」分頁建立,第一次批售前先建好。

## 側欄數字

側欄「批售單」旁的數字,是**出貨確認在你手上、還沒決定的批售單數**。

- **找出是哪幾張**:在申請中心的「待我審核」(待處理)可以看到這些批售單,打開就能收款、核准。
- 滑鼠移到數字上(手機、平板請長按數字)會顯示這個數字算的是什麼。沒有就不顯示,超過 99 顯示「99+」。
- 還沒收齊的錢另外算在帳戶管理「待結清款項」的數字裡。

## 常用操作

- **新增批售單**:按 [+ 新增批售單],選出貨分店、批售客戶與收款方式,再加入要賣的本。加入的方法有兩種:刷這本任何一張的條碼(背面編號、正面編號或正面條碼),或按 [從可批售的本加入] 勾選。可批售的本 = 出貨分店庫存裡未拆的整本;拆過、調貨中、批售中的本不會列出。按 [送出];還沒選完可以先按 [存草稿]。
- **刷到不能批售的本**:輸入框下方會當下寫原因,例「拆過的本不能批售」「調貨中(T-0012),不能批售」「批售中(W-0003),不能批售」「在別家店,不能批售」,不會加進明細。拆過又全部收回的本也算拆過,不能批售。
- **刷條碼**:刷背面編號會自動認出遊戲;刷正面條碼時,如果出貨分店有兩款以上的遊戲用同一個本號,請先選「正面條碼的遊戲」。
- **批購金額率**:每一本預設帶遊戲的「預設批購金額率」,可以逐本改,也可以在組標題列一次改整組;改過的列會標色。批售金額 = 整本金額 × 批購金額率;單的批售金額 = 各本合計,就是這張單要向客戶收的錢。
- **原成本與預估獲利**:有看成本權限的人,底部另外看得到原成本(這些本現在的成本合計)與預估獲利(批售金額 − 原成本);預估獲利是 0 或負數時會提示「照這個批購金額率沒有獲利」,照樣可以送出。
- **收款方式**:開單時二選一。
  - **收到錢再核准**(預設):送出後就可以在結算區按 [收款] 登記客戶付的錢(銀行或現金,可以分次)。收齊了店長才能核准出貨。
  - **從帳戶入帳**:選入帳帳戶(只列出貨分店可以用的帳戶;只有一個時系統預設帶入)。核准前不能收款;店長核准時,系統自動在這個帳戶記一筆「批售收入」= 批售金額。適合客戶已經確定匯款、核准前不必逐筆登記的情況。
- **收款、退款、沖正**:在批售單的「結算」區塊(從申請中心打開也看得到)。按鈕先填的金額就是剛好結清的金額:[收款] 先填還沒收的錢,[退款] 先填多收的錢。現金可以收進小金庫或開著班的收銀點抽屜,經手人要填;從小金庫退現金時,金額不能超過小金庫目前應有的錢。記錯的收付按 [沖正]。
- **出貨確認**:出貨分店的店長在申請中心打開批售單,核對本清單後核准;核准就是出貨,單據完成。店長自己開的單,任務也會派給自己,收到錢後自己核准。
- **修改草稿或被退回的單**:按 [編輯] 會打開和新增時一樣的畫面,帶入原本的內容。
- **批售出貨單**:店長核准(出貨)後自動印批售出貨單兩聯:第 1 聯 店鋪留存、第 2 聯 客戶留存,列出貨分店、批售客戶、出貨時間、本清單、批售金額合計、收款方式與已收,請經手人簽名、客戶簽收;單上不印原成本與獲利。在批售單上方按 [列印] 也可以再印,遺失或破損時按 [補印]。
- **批售收款收據**:[收款] 選現金、記好之後自動印批售收款收據兩聯:第 1 聯 店鋪留存、第 2 聯 客戶留存;轉帳不印。這家店沒有設定印表機時不送列印,核准、收款照常。
- **列表**:顯示單號、出貨分店、批售客戶、收款方式、本數、批售金額、結算(待收 / 待退 / 已結清)與狀態;可以依狀態(包含草稿)、出貨分店、批售客戶、收款方式篩選。
- **查帳**:每一筆收付列在批售單的結算區;批售客戶的詳情有「批售紀錄」分頁,列出這位客戶的批售單;本的詳情時間軸有「批售」「取消批售」。

## 重要規則

- **只賣未拆的整本**:不能選張批售,拆過的本也不能批售。
- **送出後就鎖住(批售中)**:單上的刮刮樂不能賣(收銀點刷到會提示「這張刮刮樂在批售單 #W-0001,不能賣」)、不能拆、不能調貨、不列進盤點。
- **核准前要收齊**(收到錢再核准):已收比批售金額少時不能核准,提示「還差 N 元沒收」;收多了也不能核准,提示「多收 N 元,請先記退款」。
- **從帳戶入帳的帳戶要能用**:核准時入帳帳戶已經停用、或不再給出貨分店使用,會擋下;請退回改帳戶或收款方式。退回後改成「從帳戶入帳」時,這張單已經登記過的收款要先退款或沖正到 0。
- **少收或多收怎麼補**(從帳戶入帳):核准後發現客戶匯的錢和批售金額不一樣,在帳戶管理的「待結清款項」或批售單的結算區用 [收款] / [退款] 補記,或把自動記的那筆 [沖正] 後再自己記。
- **匯款被扣手續費**:批售單只管批售金額。客戶匯款被扣手續費時,[收款] 照批售金額全額記,單據就結清、可以核准;手續費要記的話,另外在帳戶管理的帳戶詳情 [登記交易] 選「其他」、支出,摘要寫「匯款手續費」。
- **沒有先交貨、後收錢**:收到錢之前,本一直鎖住不能賣;不賣了就取消這張批售單。
- **取消批售**:
  - 審核中、還沒收錢:店長 [駁回],或申請人 [撤回],本就解除鎖定。
  - 審核中、已經收了一部分:先 [退款] 或 [沖正] 到 0,再 [駁回];已收的錢不是 0 時不能駁回。
  - 已完成(已出貨):只在登記錯誤、刮刮樂還在我們手上時 [作廢],要填作廢原因;結算要先退款或沖正到 0。作廢後這些本回到出貨分店庫存,仍是未拆、成本不變。
- **退回或撤回**:本解除鎖定,結算紀錄保留;重新送出時會再檢查一次、再鎖住。
- **刪除草稿**:只有草稿可以刪除。已經送出的單(包含被退回、撤回的)不能刪除,不要的話請駁回或作廢。
- **總部替分店建的單**:出貨分店的人看得到,但只能看、不能修改。草稿只有建立的人看得到。
- **營運報表**:批售另列在「批售」區塊(依客戶與逐單,有看成本權限的人看得到原成本與獲利),不算進收銀點的銷售與毛利。
- 沒有新增的權限時看不到 [+ 新增批售單];沒有收款的權限時看不到結算區的 [收款] [退款] [沖正]。
