# 排班作業

## 這個模組做什麼

排每一家分店的班:**排班表**、**畫休總覽**、**行事曆**、**支援需求單**(依你的權限顯示分頁)。

## 常用操作

- **畫休總覽**:選分店與月份,看每天誰整天畫休、誰時段不可排(含時間)與同日畫休人數;頂部是開放期間與還沒畫休的人,可以切換 [全部] / [尚未畫休]。
- **代改畫休**:在畫休總覽按 [代改](或點日期),選人員、日期、種類(整天畫休 / 時段不可排 + 時間)後儲存;選的人那天已登記的畫休會列出來,可以刪除。
- **行事曆**:選分店後按 [新增],設定店休或特殊日(類別、名稱、說明、顏色)。點已設定的日子可以修改或刪除。

## 重要規則

- **同日畫休人數**只計入以這家店為主要分店的人;那一天有任何畫休(整天或時段不可排)就算 1 人。
- **代改不受開放期間限制**:截止前不用填原因;截止後一定要選原因(「代改畫休原因」),選「其他」要填說明。代改會記下是誰改的。
- 代改一樣要符合規則:違反限制的不會存進去,畫面會列出原因。
- 沒有代改權限時看不到 [代改];沒有畫休總覽的權限時看不到這個分頁。

- **行事曆以最接近的那一層為準**:上層設了店休、這家店沒有另外設定 → 這家店那天也是店休;這家店自己設了特殊日 → 以這家店為準。上層設的日子在這家店只能看、不能改。
- **店休那天不能排班**,特殊日只顯示背景色、照常可以排。
- 沒有編輯行事曆的權限時看不到 [新增],點日期只看說明。

## 圖例

排班作業的畫面用同一套圖例;每個顏色、圖示在整個模組只有一個意思。

- **店休**:整天灰色,不能排班。
- **特殊日**:行事曆設定的顏色當背景,並顯示名稱。
- **負責人底色**:負責人的名字(或班表格子的範本簡稱)套綠色底。
- **「臨」**:沒有套用範本的人力需求。
- **☕ 30 分**:休息,只寫分鐘數。
- **畫休**:灰色斜線底。
- **2/2**:同日畫休人數 / 上限(只算以這家店為主要分店的人);未滿灰色、滿了橘色、超過紅色。
- **不可排**:灰色區塊(時段不可排、已排於其他分店)。
- **自動排入**:自動排班排入的人,右上角的小圖示;手動改過就消失。
- **缺負責 / 缺協同**:紅色 / 橘色的虛線空位。
