# 排班作業

## 這個模組做什麼

排每一家分店的班:**排班表**、**畫休總覽**、**行事曆**、**支援需求單**(依你的權限顯示分頁)。

## 常用操作

- **排班表**:選分店與月份。人員一人一列、日期往右捲,人員欄固定在左、統計欄固定在右;上方是人力需求區(一列一種人力需求範本,沒有套用範本的在「臨」那一列),可以收合成每天一格的彙總。
- **月 / 週 / 日檢視**:工具列的 `[ 月 | 週 | 日 | 班表 ]` 切換,看的是同一份資料、改的是同一套對話框。
  - **月**:看整個月的人力需求,每筆一個標籤(簡稱、時間與人數);點標籤修改人力需求、點空白處新增人力需求、點日期數字看那一天。月檢視不排班。手機每筆人力需求一顆點,點日期看那一天。
  - **週**:7 天各一欄,每筆人力需求一個框,框裡是填進的人;放不下的人力需求收進最右邊的「+N」,點了看清單。點框的標題修改人力需求、點人修改排班、點虛線空位排人、點空白處新增人力需求。手機是 7 天清單,點一天看那一天。
  - **日**:一天的時間軸,重疊的人力需求往下排。點工具列的日期可以從月曆選一天(日期右上角的點:紅色 = 有缺負責、橘色 = 只缺協同,排滿不畫)。手機是人力需求卡片,上下班時間和人力需求不同時會加註(例「比需求早 30 分」)。
- **新增人力需求**:按 [+ 人力需求],或點人力需求區的空白格(帶入日期與那一列範本的時間、崗位、執行任務)。填日期、時間、崗位,加負責人(0–1 筆)與協同(0–10 筆)的執行任務;勾「同時存成人力需求範本」可以順便存成範本。店休那天不能建人力需求(日期欄的店休日是灰的;跨午夜做進隔天店休也不行)。
- **排班**:點人員那天的空白格,或按 [+ 新增排班]。填上下班時間(休息依規則預設帶入,可以改),在「加入這天的人力需求」選要填進哪一筆;選了人力需求會自動填第一個空的執行任務(還缺負責、這個人又可以擔任負責人 → 負責,否則協同;只剩負責可以填時照樣填負責),可以再改。這天沒有合適的人力需求時,按標題列右邊的 [新增一筆人力需求] 直接新增一筆,回來後會自動加一列;上下班時間還沒填的話,會帶入這筆人力需求的時間。
- **存不了的原因寫在欄位下**:那天店休、和這個人的畫休重疊,上班欄下會寫原因(那天店休時 [新增一筆人力需求] 也不能按;人力需求對話框則寫在開始時間欄下);選的人不能擔任負責人卻填了負責任務,「加入這天的人力需求」下會寫原因。這時 [儲存] 不能按,改掉就可以存。下拉裡不能選的任務是灰的,旁邊寫原因(誰已經填了、這個人不能擔任負責人)。
- **修改 / 刪除**:點已排的班打開排班對話框;點人力需求區的人數標籤打開人力需求對話框。日期欄的 [⋯] 可以 [移除這天所有排班](颱風停班等)。
- **[⚙ 顯示欄位]**:勾選統計欄要顯示哪幾欄(班數、負責班數、總工時、畫休天數、最長連續上班),跟著帳號記住,換一台裝置登入也一樣。
- **畫休總覽**:選分店與月份,看每天誰整天畫休、誰時段不可排(含時間)與同日畫休人數;頂部是開放期間與主要分店是這家、還沒畫休的人,可以切換 [全部] / [尚未畫休]。
- **代改畫休**:在畫休總覽按 [代改],先選人員、日期(日期不限畫休總覽正在看的月份;選好後上方會列出這個人那天已登記的時段不可排,選到別的月份時會先顯示「載入這天已登記的時段…」,載入完才能儲存),再選種類(整天畫休 / 時段不可排 + 時間;時段可以按 [+ 再加一段] 一次登記多段;要做到當天結束,結束選 00:00)後儲存。整天不可排請選整天畫休:選 00:00–00:00,或這次填的幾段連同那天已登記的合起來剛好一整天,都不能儲存。
- **刪除畫休**:在畫休總覽點日期,會列出那天所有人的畫休,每筆旁邊有 [刪除];按下去會先請你確認,已經截止的月份要在確認框裡選原因。這個視窗下方的 [代改] 會帶入那天。看的是這個月以前的月份時,上方和這個視窗都沒有 [代改]。
- **行事曆**:選分店後按 [+ 新增店休 / 特殊日],設定店休或特殊日(類別、名稱、說明、顏色)。特殊日的類別、名稱與顏色必填;顏色不能選灰色(灰色代表店休 / 不能排)。點已設定的日子可以修改或刪除。設成店休時,那天已經有人力需求或排班(上層設的會列出沿用那天的各店)照樣存,存檔後會提醒;請到排班表的週或日檢視把那天的人力需求刪掉(有人填的會一起解除),店休那天的人力需求只能刪、不能改。
- **支援需求單**:分店人手不夠時請總部支援。按 [+ 新增支援需求單],填開始與結束(日期與時間)、崗位、需要人數、分店與說明後 [送出]。送出後會拿到單號(例 SP-0001)。列表顯示單號、開始、結束、崗位、需要人數、分店與狀態,可以依狀態篩選;點一筆在右側看內容,輪到你審核時右側有 [退回修改] / [駁回] / [核准](手機與平板會打開詳情頁)。
- **套用範本**:按 [套用範本](這個月還沒有人力需求時畫面中間也有),在右側(手機全螢幕)選種類:
  - **人力需求範本**:可以選好幾個,會加到選取的每一天,即使那天已經有其他人力需求;同一天崗位和時間完全相同的會略過(只是時間重疊的照常加)。
  - **人力需求週範本**:選一份,依星期幾補上人力需求;**只補完全沒有人力需求的日子**,已經有任何人力需求的日子不會變動(月曆上標「已有」)。不同週要用不同週範本時,分兩次套用。
  - 套用到的日子預設整個月全選,點一下取消;可以用 [全選] [全不選] [平日] [週末],或勾每週左邊的框選整週。店休的日子不能選。下方會先算好「將產生幾個時段、略過幾個」,按 [套用] 才會建立。
- **自動排班**:按 [自動排班],選範圍(預設整個月)與方式 —— [只填空位]、[重排自動排入的人](手動排的不動)、[全部重排](連手動排的一起清掉,會先問你要不要清)。條件可以勾選、拖拉調整順序(預設照排班設定 → 規則的自動排班條件,改了只用在這一次)。這家店有設定預設人力需求週範本時,可以勾「先以『…』補上人力需求」,先把沒有人力需求的日子補上再排人。排完回到排班表,右邊的檢核面板會自動打開,最上方寫這次填入幾人次、補上幾天的人力需求。
- **清除自動排入的人**:在檢核面板最上方按 [清除自動排入的人],選日期範圍後確認;只移除自動排入的人,手動排的、或自動排入後你改過的不會清除。清完沒有任何人力需求可填的排班會一起刪除。自動排班為了延續而把原本的班延長的,會縮回原本的時間;延長後你改過那筆排班就維持現狀。
- **檢核**:排班表右上的檢核按鈕寫著「限制 1 · 提醒 3」(沒有問題時是灰色的勾),點了在右邊(手機在下方)打開檢核面板。可以篩選 [全部] [限制] [提醒];每一項寫違反哪條規則與哪個人、哪一天,按 [查看] 會捲到排班表那一格並閃爍。改完排班,面板會馬上重新檢查。
- **發布**:按 [發布],會用當下最新的規則重新檢查整個月:全部符合 → 確認後發布;只有提醒 → 列出提醒,可以 [仍要發布];有違反限制 → 不能發布,先改好再發布。發布後員工的「我的班表」看得到,並通知被排到的人。
- **未對應排班的打卡**:有人打了卡、但沒有對應到排班時,班表格子右上角出現時鐘圖示和張數(週 / 日檢視在日期旁、月檢視在日期格右上角)。打開那人那天的排班對話框,下方會列出這些卡,勾選的卡儲存後就對應到這筆排班;那天沒有排班(臨時代班)時點格子的時鐘圖示會開新增排班。店休那天的格子也會顯示時鐘圖示,但店休不能排班,只標示不能點。
- **發布後修改**:人力需求對話框、排班對話框與 [移除這天所有排班] 多一欄「異動原因」(必填,選「其他」要填說明),存了直接生效,並通知異動牽涉的人。

## 重要規則

- **總部替分店建的單**:總部替分店建的支援需求單,看得到單上分店的人(該分店的人、看得到該分店的上層組織的人)也看得到,但只能看、不能修改或刪除;草稿只有建立的人看得到。
- **一筆執行任務只填一個人**;一筆排班可以填進好幾筆人力需求,但同一筆人力需求只能選一次。要多一個人,就在人力需求加一筆協同。
- **每筆排班至少要填進一筆人力需求**:移除最後一列時不能儲存;不要這筆排班請按 [刪除這筆排班]。
- **同一個人同一時間只能有一筆排班,跨分店也一樣**;別家分店的班會在他的列上顯示灰色「已排於…」。
- **跨午夜的班**:人力需求與排班的結束時間不晚於開始時間,就算到隔天(例 22:00–02:00),日期算開始那天;要做到當天結束,結束選 00:00。
- **負責人要涵蓋整段人力需求**:上下班時間沒涵蓋時會提示,可以一鍵往前或往後延長;協同可以只上一段。
- **刪除人力需求或移除有人填的執行任務**:會先列出要解除的人;解除後一筆都沒填的排班會一起刪除。已經有開班紀錄的排班不能刪,要先改那筆排班。
- **負責班數**以排班為單位(這筆排班任一筆是負責就算 1 班);**總工時**算到分鐘(下班 − 上班 − 休息);**畫休天數**那天有任何畫休就算 1 天,超過上限會變色。
- 沒有修改排班表的權限時看不到 [+ 人力需求] [+ 新增排班] 與日期欄的 [⋯],點格子只能看。

- **同日畫休人數**只計入以這家店為主要分店的人;那一天有任何畫休(整天或時段不可排)就算 1 人。
- **代改不受開放期間限制**:截止前不用填原因;截止後一定要選原因(「代改畫休原因」),選「其他」要填說明。代改會記下是誰改的。
- **代改會通知員工本人**:代改儲存一次通知一則(列出這次登記的所有時段或整天畫休),刪除一筆也通知一則;內容寫日期、時段、誰改的和原因。替自己代改不會通知。員工可以在個人設定的偏好裡關掉這種通知。
- 代改一樣要符合規則:違反限制的不會存進去,畫面會列出原因。
- 沒有代改權限時看不到 [代改];點日期只能看那天所有人的畫休,沒有 [刪除] 和 [代改]。沒有畫休總覽的權限時看不到這個分頁。

- **行事曆以最接近的那一層為準**:上層設了店休、這家店沒有另外設定 → 這家店那天也是店休;這家店自己設了特殊日 → 以這家店為準。上層設的日子在這家店只能看、不能改。
- **店休那天不能排班、也不能建人力需求**(跨午夜做進隔天店休也一樣;套用範本也不會產生),特殊日只顯示背景色、照常可以排。
- 沒有編輯行事曆的權限時看不到 [+ 新增店休 / 特殊日],點日期只看說明。

- **支援需求單沒有草稿**:新增頁只有 [送出],送出後就進入審核。
- **誰審核支援需求單**:屬於最上層組織、而且有「總部管理」角色的人;總部在排班作業把支援的人排好後再核准。被退回的單可以改好再送出。
- 時間用 24 小時制(例 17:00),結束要晚於開始,而且要在同一天;**不能跨午夜**,例如 22:00 到隔天 02:00 要拆成兩張(22:00–23:59、隔天 00:00–02:00)。

- **限制與提醒**:每條規則可以設成「限制」或「提醒」(排班設定 → 規則)。違反限制的排班存不進去、這個月也不能發布;提醒照樣可以存與發布。改了規則不會改已經排好的班,只會重新檢查並標出來。
- **每天最多上班時數**把同一天所有的班加總(同店多段、跨分店都算),跨午夜的班算在開始那天;**兩班之間最少休息**看前一天最後下班到後一天第一次上班;**人力不足**列出還空著的執行任務,並寫那段時間還有幾個人可以排,沒有人可排時寫原因(畫休、時段不可排、已排其他班、不能擔任負責人)。
- **畫休日有排班**:先排了班、後來那天登記了畫休,檢核會列出來(含其他分店的班;看不到的分店只寫「其他分店」),請調整班表。
- **自動排班一定遵守**:畫休(整天或時段不可排)、店休、等級為限制的規則;一筆執行任務只排一個人;負責的執行任務只排可以擔任負責人的人;新排的班休息依規則「預設休息」。沒勾「允許同一人同時段填進多筆人力需求」時,不會讓同一個人同時顧兩台。排不滿的會列在檢核的「人力不足」。
- **自動排班怎麼挑人**:依勾選的順序比較 ——「延續同一人的排班」:同一家店時間相接的人力需求,優先給已經排了前一段的人(把那筆排班延長,不會中間空一段);「負責人次數多者優先」:過去 90 天在這家店當負責人次數多的先(只用在負責的執行任務);「本月班數平均」:這個月班數少的先。前一個條件比不出來才比下一個,全部一樣就隨機。滑過自動排入的人可以看到理由。
- **自動排班執行中**:有人在執行自動排班時,這個月暫時不能修改,其他人的 [自動排班] 會寫「自動排班執行中」;最久 10 分鐘後自動解除。
- 自動排入的人被你改過(打開排班對話框存檔)就算手動排的,自動排入的小圖示會消失。
- 只有未發布的月份能自動排班;發布後不再顯示 [自動排班]。沒有自動排班的權限時看不到 [自動排班];沒有修改排班表的權限時看不到 [套用範本]。
- **未對應排班的打卡**:排班對話框預設勾選排班時間前後「對應排班容許時間」(預設 60 分鐘)內的卡;同一班多打的卡標「重複打卡」、預設不勾。只有上班沒有下班的卡照樣可以對應,之後出勤紀錄會顯示缺卡,由本人申請補打卡。檢核面板會列出「未對應排班的打卡」(提醒,不影響發布)。
- **上下班時間改用打卡時間**:預設不勾;勾了上下班時間換成勾選的卡中最早的上班與最晚的下班。沒有這個權限時看不到這個選項。
- **未發布**的月份員工看不到,不會通知任何人;**發布後不能改回未發布**。
- 沒有發布權限時看不到 [發布];已發布的月份不再顯示 [發布]。

## 圖例

排班作業的畫面用同一套圖例;每個顏色、圖示在整個模組只有一個意思。

- **店休**:整天灰色(週 / 日檢視那一天、班表那一欄、月檢視那一格),不能排班、也不能建人力需求。
- **特殊日**:行事曆設定的顏色當背景(週 / 日檢視那一天、班表整欄、月檢視整格),並顯示名稱。
- 手機日檢視在卡片清單上方一列標示那天是店休(灰色)或特殊日(它的顏色與名稱)。
- **負責人底色**:負責人的名字(或班表格子的範本簡稱)套綠色底。
- **「臨」**:沒有套用範本的人力需求。
- **☕ 30 分**:休息,只寫分鐘數。
- **畫休**:灰色斜線底。
- **2/2**:同日畫休人數 / 上限(只算以這家店為主要分店的人);未滿灰色、滿了橘色、超過紅色。
- **不可排**:灰色區塊(時段不可排、已排於其他分店)。
- **自動排入**:自動排班排入的人,右上角的小圖示;手動改過就消失。
- **缺負責 / 缺協同**:紅色 / 橘色的虛線空位;人力需求區的人數標籤缺負責是紅色、缺協同是橘色,已滿是灰色。
- **已排的班**:淡黃色底的格子,寫範本簡稱、時間與休息。
- **×2**:同一筆排班同一段時間填進兩筆人力需求(一人顧兩台),例「晚 ×2」。
- **⏲ 2**:那天有幾張還沒對應到排班的打卡(班表格子右上角(店休的格子也會標示)、週 / 日檢視日期旁、手機日檢視卡片上方、手機週清單日期旁、月檢視日期格右上角)。要處理請點班表格子的時鐘圖示(月檢視只標示,到班表檢視或出勤紀錄處理)。
- **超出人力需求的時間**:上下班時間超出人力需求的那一段,同一條長條延伸出去,淡色底 + 虛線框。
- **「+N」**:週檢視放不下而收起的人力需求,點了看清單;框線是紅色 = 裡面有缺負責、橘色 = 有缺協同、灰色 = 都已滿。
- **實心點**:手機月檢視每筆人力需求一顆,灰色已滿、橘色缺協同、紅色缺負責;日檢視選日期的月曆每天最多一顆,取當天最嚴重的狀態(紅色有缺負責、橘色只缺協同),排滿不畫。
