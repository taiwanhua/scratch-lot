# 刮刮樂設定

## 這個模組做什麼

設定各分店的刮刮樂做法:**盤點制度**、**張數店補點編號**、**補點編號提醒**、**調貨單可點格子選張**。

最上層組織給預設,每家分店沿用;區域或分店也可以自己設一個值(自訂)。一家分店實際用的值,是從分店往上找:分店有自訂就用分店的,沒有再看區域,再看最上層組織,都沒有就用系統的預設值。

## 常用操作

- **看某家分店的設定**:上方「分店」選要看的組織(網址會記住)。每一列是一條設定:名稱、現在的值、來源。來源寫「本店自訂」是這一層自己設的,寫「沿用:某某」是跟著上層,寫「程式預設」是整條都沒設。自訂的列下方灰字是上層的值。
- **自訂**:按那一列的「自訂」(或點整列),選值後按「儲存」。
- **還原**:按「還原」刪掉這一層的自訂,回到跟著上層。
- **看盤點制度的變更紀錄**:分店的盤點制度那一列有「變更紀錄」,列出每次從哪種改成哪種、什麼時候、誰改的。

## 盤點制度怎麼選

- **編號盤點**(編號店):每張都刷條碼或點格子才賣,盤點逐張。適合生意較少、來得及逐張對編號的分店。
- **張數盤點**(張數店):檯面可以依張數標記售出,檯面盤點只數張數;檯面上的張號由系統預設帶入,刷到實體時會自動對號更正。適合生意好、來不及逐張對編號的分店。

**改成張數盤點**:當下生效,下一次盤點起改數張數。檯面上還有待標註的本時不能改,對話框會列出這些本,請先到看板標完跳號再改。

**改回編號盤點**:還有系統預設帶入的張號時,分店先進入**轉換中**,做完一次全店補點編號並核准後才改成編號盤點。轉換中不能依張數標記售出、依張數移櫃,其他照張數店的做法;盤點制度那一列會寫「張數盤點 → 編號盤點(轉換中,等補點編號)」。沒有系統預設帶入的張號時直接改成編號盤點。

**取消轉換**:轉換中的分店可以按「取消轉換」,當下回到張數盤點。取消轉換等於幫這家店自訂「張數盤點」,之後上層的預設再改也不會跟著動,要按「還原」才恢復沿用。

**在上層改預設**:對話框會列出會跟著改的分店(自己有自訂的分店不跟著改)。其中有分店檯面上還有待標註的本、或正在盤點、全店重刷、補點編號時,這次不能存;請先處理那家店,或先幫那家店「自訂」成原本的制度。

## 補點編號

- **張數店補點編號**:「只提醒」(預設)只在關帳時警告;「必須」時,該月最後一次日結前沒做補點編號就不能關帳。從「必須」改成「只提醒」時,這個月關帳改成只警告,報表會標估算並註記「月底未補點編號」,這次變更會留紀錄。
- **補點編號提醒**:不設 / 每週 / 雙週 / 每月(預設每月),決定多久提醒一次補點編號。

## 重要規則

- 分店正在盤點、全店重刷、補點編號還沒結束時,不能改盤點制度,完成或結束後再改。
- **調貨單可點格子選張**只對編號店有效;張數店的調貨單一律只能刷條碼或手輸張號。
- 所有變更都會留紀錄。
- **看得到的按鈕就是你做得了的事**:沒有「自訂」「還原」「取消轉換」,代表你沒有改這一層設定的權限(最上層組織的預設與區域、分店的設定是分開的權限),需要時請洽系統管理員。
