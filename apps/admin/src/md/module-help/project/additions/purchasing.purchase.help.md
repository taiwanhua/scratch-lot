# 進貨單

## 這個模組做什麼

總部向甲類**批購**刮刮樂後開**進貨單**,送貨到分店時,分店店長**逐本刷條碼點收**,點收後的刮刮樂才進到這家店的庫存。進貨單也記這次批購的**結算**(付款、收到退款)。

## 側欄數字

側欄「進貨單」旁的數字,是**等你點收的進貨單數**:點收這一關在你手上、還沒點收完成的進貨單。

- **找出是哪幾張**:在申請中心的「待我審核」(待處理)可以看到這些進貨單,打開就能點收。
- 滑鼠移到數字上(手機、平板請長按數字)會顯示這個數字算的是什麼。沒有就不顯示,超過 99 顯示「99+」。
- 全部點收並核准後,這張就不再算;分次點收時,還沒核准前都照算。

## 常用操作

- **新增進貨單**:按 [+ 新增進貨單],選進貨分店、批購甲類、本人批購(選「否」時要選批購受託人)、批購日期(預設今天)與扣款帳戶(只有一個時自動帶入),再刷每一本**最後一張**的條碼加入明細,按 [送出]。還沒刷完可以先按 [存草稿]。
- **修改草稿或被退回的單**:按 [編輯] 會打開和新增時一樣的畫面,帶入原本的內容。已點收的本標「已點收」,不能改也不能移除(每組標題會顯示「已刷 2,已點收 1 / 2」);還沒點收的本可以改批購金額率、移除,也可以再刷新的本。有已點收的本時不能換進貨分店。送出後回到點收,由進貨分店點收剩下的本。
- **從叫貨單帶入**:在叫貨、採購單的採購清單按 [建立進貨單],或在新增頁選叫貨單;畫面會顯示「叫貨 5,已刷 4」,方便對照還差幾本。
- **刷條碼**:刷背面編號會自動認出遊戲;刷正面條碼時要先選「正面條碼的遊戲」。同一本刷兩次會提醒已經在單上。
- **兌獎**:新增頁的「兌獎」區列出進貨分店還在店裡(店內持有)的兌獎紀錄(第一欄是兌獎紀錄的單號),勾選這次拿去兌獎的兌獎紀錄。兌獎金額 = 勾選的合計,不能手填。合計會多三列:兌獎金額、兌獎折抵(兌獎金額與批購合計取較小者)、兌獎剩餘;扣款金額 = 批購合計 − 兌獎折抵。
- **批購金額率**:預設是遊戲的批購金額率,可以逐本改,也可以在每組的標題列一次改整組;改過的會標色。批購金額 = 整本金額 × 批購金額率。
- **點收**:店長從申請中心或通知打開進貨單(在進貨單打開也可以),在「點收」區塊逐本刷條碼(刷這本的最後一張)。每組標題會顯示叫貨本數(有叫貨單時)、單上本數與已點收幾本,例「叫貨 5,已刷 4,已點收 2 / 4」。可以分次點收:刷完這一批按 [完成這次點收],之後到貨再繼續刷。
- **點收時同一個本號有好幾款遊戲**:刷正面條碼時,如果單上有兩款以上的遊戲用同一個本號,會先擋下並出現「正面條碼的遊戲」選單;請改刷背面編號,或選是哪一款遊戲,就會照你選的遊戲點收。
- **進貨點收單**:按 [完成這次點收] 時自動印進貨點收單兩聯:第 1 聯 店鋪留存、第 2 聯 送貨人留存(一次印出、兩聯中間切開,算印 1 次),每聯標題下方印聯別,上面列這次點收的本與尚未到的本,請點收人與送貨人簽名。每按一次 [完成這次點收] 就是一張進貨點收單(單上印「第幾次點收」)。印好之後,進貨單上方的按鈕會變成 [補印],並顯示「已印 1 次」。
- **自己按 [列印]**:還沒印過(例如自動列印沒印出來)時,按 [列印] 先選要印哪一聯(兩聯都印、第 1 聯、第 2 聯,預設兩聯都印)。只印第 1 聯也算印了第 1 次,之後要印第 2 聯請按 [補印]。
- **補印進貨點收單**:單據遺失或破損時,在進貨單上方按 [補印]:點收過兩次以上時,先在 [補印] 旁的「點收批次」選要補印哪一次(預設最近一次);再選要補哪一聯(兩聯都補、第 1 聯、第 2 聯,預設兩聯都補)與補印原因後送出。補印的內容和原來那一張一樣,每一聯上方另印「【補印】第幾次」、時間、原因與補印人。次數以「次」計:原來那一次是第 1 次,第一次補印是第 2 次。
- **刪除草稿**:只有草稿可以刪除(自己的草稿,列表與進貨單上方會有 [刪除]),刪除前會再確認一次。已經送出的單(包含被退回、撤回的)不能刪除,不要的話請作廢或駁回。
- **列表**:顯示單號、進貨分店、甲類、批購日、扣款金額、點收進度(例 8 / 10)、結算(待付 / 待退)與狀態,可以依狀態篩選(包含草稿)。
- **結算**:檢視頁的「結算」區塊列出應付、已付與差額,以及每一筆付款的紀錄;可以按 [付款] [收到退款] [沖正]。

## 重要規則

- **總部替分店建的單**:總部建的進貨單,看得到單上進貨分店的人(該分店的人、看得到該分店的上層組織的人)也看得到,但只能看、不能修改或刪除,也不能按付款等結算按鈕;草稿只有建立的人看得到。
- **送出時自動記一筆「進貨支出」**:金額 = 扣款金額,從扣款帳戶扣,這就是這張單的應付;扣款金額是 0 時也會記一筆 0 元。之後退回修改再送出**不會自動調整**,結算區塊會顯示「待付」或「待退」,請用 [付款] 或 [收到退款] 補齊。
- **兌獎的進貨單送出後**:勾選的兌獎紀錄改成「已送兌」;撤回、退回、駁回或作廢後回到「店內持有」。兌獎剩餘大於 0 時,同時自動記一筆銀行「兌獎入帳」(存入扣款帳戶);這是兌獎拿回來的錢,不算這張單的款項,不會出現在待付 / 待退。只能勾進貨分店的兌獎紀錄。
- **本號不能重複**:同一張單、其他還有效的進貨單或已經在庫存裡的本,本號都不能重複,送出時會擋下。
- **超過預計要給本數只提醒**:進貨分店已給 + 在途 + 這張單刷的本數超過預計要給本數時,新增頁會列出超過的遊戲,照樣可以送出。
- **停售的遊戲不能進貨**。
- **刷到的最後張號和單上不同會擋下**:請退回這張單,修改那一本的最後張號再送出。
- **已點收的本不能改或刪**:退回修改時只能改還沒點收的本。
- **全部點收後才能核准**;已經點收過的進貨單不能駁回或刪除。
- **送錯分店**:刷到不是送到這家店的本會擋下,不會入庫,畫面會告訴你這本是哪一家店的哪一張進貨單,請交給送貨人帶過去。[知道了] 不會記錄任何東西;如果是單子寫錯(這本其實是給你這家店的),按 [通知總部更正],這張進貨單的建立者會收到通知。
- **作廢**:要填作廢原因;任何一張刮刮樂已經賣出、調出或拆本時不能作廢。作廢或駁回前結算要先歸零(已付淨額是 0)。作廢後點收進來的本會撤銷,叫貨單回到待購買。
- **批購日**:送出後甲類的最近批購日(本人批購另算)會更新;駁回或作廢後重新計算。
- **草稿不算數**:草稿只有自己看得到,不記帳、不算在途。
- **誰點收**:進貨分店的「店長」。點收中的進貨單會算在側欄「進貨單」的數字裡。
- **列印**:這家店沒有設定印表機時 [列印] 是灰的,滑過去會說明原因;沒有列印權限時不會出現 [列印],也不會自動列印,點收照常完成。印表機請找管理員在「印表機管理」設定。
- 沒有結算的權限時看不到 [付款] [收到退款] [沖正];沒有新增的權限時看不到 [+ 新增進貨單]。
