# 班表管理

## 這個模組做什麼

排班與出勤:誰在哪一家分店、什麼時間上班,每天需要多少人力,以及打卡與出勤紀錄。分成四個功能:

- **我的班表**:看自己已發布的班、打卡、登記畫休。
- **排班作業**:排班表、畫休總覽、**行事曆**、支援需求單。
- **排班設定**:**排班人員**、**人力需求範本**、**人力需求週範本**、**規則**。
- **出勤紀錄**:依人員或依分店看打卡、補打卡申請。

## 常用操作

- **加入排班人員**:排班設定 → 排班人員,篩選「未加入」,勾選要排班的人後按 [加入排班]。排班人員不是新建帳號,是從使用者管理已有的帳號挑人;找不到人時先到使用者管理新增帳號。
- **設定可以排的分店**:點已加入的人,選僱用類型(正職 / 兼職)、加上可以排的分店,每家店可以勾「可擔任負責人」,並選一家「主要分店」。只能加你看得到的分店。
- **建立人力需求範本**:排班設定 → 人力需求範本 → [+ 新增人力需求範本],填名稱、簡稱(1–2 字)、開始與結束時間(到分鐘)、崗位、負責人(最多 1 筆)與協同(最多 10 筆)的執行任務,並從色票選一個顏色。新增一筆負責人或協同時,會帶入規則裡的預設任務。
- **建立人力需求週範本**:排班設定 → 人力需求週範本,為星期日到星期六各勾選要用的人力需求範本。
- **調整規則**:排班設定 → 規則,選分店後,在要調整的那一條按 [自訂],設定值、違反時是「限制」還是「提醒」以及排序;按 [還原] 回到沿用上層的設定。
- **行事曆**:排班作業 → 行事曆,選分店後按 [新增],設定店休或特殊日(類別、名稱、說明、顏色)。

## 重要規則

- **上層建立的範本,下層都能用、但改不了**:人力需求範本與週範本只有建立它的那一層能修改,列表的「建立於」寫的就是那一層。
- **規則沿用上層**:分店沒有自訂的規則,沿用上層的設定(畫面寫「沿用:<上層名稱>」;看不到上層時寫「沿用上層設定」);自訂的規則下方會用灰色小字顯示上層的值。自動排班條件是**整組**一起沿用或自訂。
- **限制與提醒**:違反「限制」的排班不能存、不能發布;「提醒」照樣可以存與發布。改了規則不會自動修改已經排好的班,只會重新檢查並標示出來。
- **行事曆以最接近的那一層為準**:上層設了店休、這家店沒有另外設定 → 這家店那天也是店休;這家店自己設了特殊日 → 以這家店為準。店休那天不能排班,特殊日只顯示背景色、照常可以排。
- **看得到的按鈕就是你做得了的事**:沒有對應權限時,看不到 [加入排班]、[+ 新增人力需求範本]、[自訂]、[還原]、行事曆的 [新增]。

## 圖例

班表管理的畫面用同一套圖例;每個顏色、圖示在整個模組只有一個意思。

- **負責人底色**:負責人的名字(或班表格子的範本簡稱)套綠色底。
- **「臨」**:沒有套用範本的人力需求。
- **☕ 30 分**:休息,只寫分鐘數。
- **畫休**:灰色斜線底。
- **不可排**:灰色區塊(時段不可排、已排於其他分店)。
- **自動排入**:自動排班排入的人,右上角的小圖示;手動改過就消失。
- **店休**:整天灰色,不能排班。
- **特殊日**:行事曆設定的顏色當背景,並顯示名稱。
- **缺負責 / 缺協同**:紅色 / 橘色的虛線空位。
