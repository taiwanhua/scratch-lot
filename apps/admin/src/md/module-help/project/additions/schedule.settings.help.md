# 排班設定

## 這個模組做什麼

排班前要先準備好的設定,分成四個分頁:**排班人員**、**人力需求範本**、**人力需求週範本**、**規則**。

## 常用操作

- **加入排班人員**:在「排班人員」篩選「未加入」,勾選要排班的人後按 [加入排班]。排班人員不是新建帳號,是從使用者管理已有的帳號挑人;找不到人時先到使用者管理新增帳號。
- **設定可以排的分店**:點已加入的人,選僱用類型(正職 / 兼職)、加上可以排的分店,每家店可以勾「可擔任負責人」,並選一家「主要分店」。只能加你看得到的分店。
- **建立人力需求範本**:在「人力需求範本」按 [+ 新增人力需求範本],填名稱、簡稱(1–2 字)、開始與結束時間(到分鐘;結束不晚於開始 = 到隔天,做到當天結束選 00:00)、崗位、負責人(最多 1 筆)與協同(最多 10 筆)的執行任務,並從色票選一個顏色。新增一筆負責人或協同時,會帶入規則裡的預設任務。
- **建立人力需求週範本**:在「人力需求週範本」為星期日到星期六各勾選要用的人力需求範本。
- **調整規則**:在「規則」選分店後,在要調整的那一條按 [自訂],設定值、違反時是「限制」還是「提醒」以及排序;按 [還原] 回到沿用上層的設定。

## 重要規則

- **上層建立的範本,下層都能用、但改不了**:人力需求範本與週範本只有建立它的那一層能修改,列表的「建立於」寫的就是那一層。
- **規則沿用上層**:分店沒有自訂的規則,沿用上層的設定(畫面寫「沿用:上層名稱」;看不到上層時寫「沿用上層設定」);自訂的規則顯示「本店自訂」,下方用灰色小字顯示上層的值。自動排班條件是**整組**一起沿用或自訂。
- **限制與提醒**:違反「限制」的排班不能存、不能發布;「提醒」照樣可以存與發布。改了規則不會自動修改已經排好的班,只會重新檢查並標示出來。
- **主要分店**:每人一家;人的規則(例:每月最多畫休)用主要分店的設定。
- **看得到的按鈕就是你做得了的事**:沒有對應權限時,看不到 [加入排班]、[+ 新增人力需求範本]、[自訂]、[還原]。
