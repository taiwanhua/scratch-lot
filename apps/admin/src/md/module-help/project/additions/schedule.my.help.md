# 我的班表

## 這個模組做什麼

看自己已發布的班(跨分店合併顯示)、上下班打卡,以及在畫休開放期間登記下個月的畫休。

## 班表

以你這個人為單位,把你在各家分店已發布的班合在一起看。

### 打卡

- 打卡在班表分頁最上方:今天的班各一張卡片,上班、下班按鈕都在上面;按哪張卡片就打進哪一班。
- 昨天的班還沒打下班卡時,會多一張「昨天未打下班卡」的卡片,只能打下班卡。
- 同一班多打的卡:上班以最早那張為準、下班以最晚那張為準,多出來的記為「重複打卡」。
- **沒有排班**:沒排到班但臨時來上班時,在「沒有排班」打卡;卡記在目前選的分店,之後由店長對應到排班。今天有班時這一塊收成一行連結;今天沒班時直接展開;已經打了上班卡、還沒打下班卡時會展開並提醒你打下班卡。
- 支援別家分店的班照樣在這裡打卡。
- 沒有打卡權限的人看不到打卡按鈕。

### 打卡不完整提醒

- 頂部列出最近 7 天已經結束、但缺上班卡或下班卡的班(還沒結束的班不算)。這個提醒不能手動關閉,補好卡之後才會消失。
- 每一班旁邊有 [申請補卡],會打開補打卡申請並帶入那張卡排定的時間、分店、類型與那一班(時間請改成實際的時間);送出後顯示「補卡審核中」,核准後提醒就會消失。

### 最近異動

- 班表發布後店長又調整了你的班,上方會出現「你的班表有 2 項異動」,按 [展開] 看日期、原本 → 現在與原因。只列還沒到的班;上次打開這一頁之後才發生的標「新」。

### 月曆與條列

- 按 ◀ ▶ 換月;右上角可以切換 [月曆 | 條列](電腦、平板預設月曆,手機預設條列)。
- 每天顯示你的班(範本簡稱、時間)與打卡時間「上班 / 下班」;條列依日期列出這個月的班與打卡。
- 點一天看當天詳情:分店、時間、崗位、職責與任務內容、打卡紀錄;缺卡時會說明缺了哪張卡。

## 我的畫休

畫休是你自己登記「不能排班」的日子,不需要核准,符合規則就立即存檔。

- **整天畫休**:那一天整天都不能排;一天只能有一筆。
- **時段不可排**:那一天的某段時間不能排(例:09:00–13:00);一天可以登記多段,但不能重疊。
- 按 [登記畫休],或直接點月曆上的日期(會帶入那天),選種類;選時段不可排才要填開始 / 結束(要做到當天結束,結束選 00:00;整天都不能排請改選整天畫休;選 00:00–00:00,或幾段合起來剛好一整天(例如 00:00–12:00 加 12:00–00:00)都不能儲存)。那天已登記的會列在上方,可以刪除。
- 畫休屬於你這個人:那段時間你可以排的每一家店都不能排你。

### 怎麼算

- 那一天只要有任何畫休(整天或時段不可排)就算 **1 天畫休**,也算 **1 個畫休人數**。
- 「每月最多 / 最少畫休」用你的主要分店的規則;「同日最多畫休人數」只計入主要分店是同一家店的人。
- 「最多連續休假」只算整天畫休。

### 畫面上的資訊

- 頂部:登記哪個月、開放期間與剩幾天、「已畫 4 天 · 上限 8 · 下限 4」。
- 按 ◀ 可以看過去月份的畫休(只能看,不能修改);按 ▶ 最多回到正在登記的月份。
- 格子:你的畫休、主要分店那天的同日畫休人數「2/2」;點 ⓘ 看那天誰畫休、涉及哪些規則。
- 違規清單:列出違反的規則,按 [查看] 看那一天的詳細。
- 違反**限制**的畫休不會存進去,畫面會告訴你原因;違反**提醒**照樣存,但會列在違規清單。
- 開放期間外不能自己修改;要調整請聯絡店長或排班負責人(有代改權限的人會看到「到畫休總覽代改」)。這個月以前的月份只會提示「這是過去月份的紀錄,只能查看」,沒有這個連結。

## 重要規則

- 只顯示**已發布**的班;還沒發布的月份員工看不到。
- 畫休只能在畫休開放期間登記**下個月**的;期間外要調整請聯絡店長或排班負責人。

## 圖例

- **負責人底色**:你擔任負責人的班,範本簡稱套綠色底;沒有套用範本的班寫「臨」。
- **08:24 / 14:36**:那一班的上班 / 下班打卡時間;沒打的寫「—」。
- **● 缺卡**(紅點):日期右上角的紅點 = 那天有已結束的班缺上班卡或下班卡(電腦、平板、手機都一樣)。
- **● 有異動**(橘點):日期右上角的橘點 = 那天的班在發布後被調整過。
- **畫休**:格子寫「畫休」;時段不可排寫「09:00–13:00 不可排」。你有畫休的日子整格灰色斜線底。
- **2/2**:同日畫休人數 / 上限;未滿灰色、滿了橘色、超過紅色。
- **色帶**:違反規則的日子底部的色帶,紅色 = 違反限制、橘色 = 提醒。
- **ⓘ**:看當天誰畫休。
- **特殊日**:行事曆設定的顏色當背景,並顯示名稱。
