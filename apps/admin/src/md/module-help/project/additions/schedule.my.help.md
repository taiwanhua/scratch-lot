# 我的班表

## 這個模組做什麼

看自己已發布的班(跨分店合併顯示)、打卡,以及在畫休開放期間登記下個月的畫休。

## 我的畫休

畫休是你自己登記「不能排班」的日子,不需要核准,符合規則就立即存檔。

- **整天畫休**:那一天整天都不能排;一天只能有一筆。
- **時段不可排**:那一天的某段時間不能排(例:09:00–13:00);一天可以登記多段,但不能重疊。
- 按 [登記畫休],或直接點月曆上的日期(會帶入那天),選種類;選時段不可排才要填開始 / 結束。那天已登記的會列在上方,可以刪除。
- 畫休屬於你這個人:那段時間你可以排的每一家店都不能排你。

### 怎麼算

- 那一天只要有任何畫休(整天或時段不可排)就算 **1 天畫休**,也算 **1 個畫休人數**。
- 「每月最多 / 最少畫休」用你的主要分店的規則;「同日最多畫休人數」只計入主要分店是同一家店的人。
- 「最多連續休假」只算整天畫休。

### 畫面上的資訊

- 頂部:登記哪個月、開放期間與剩幾天、「已畫 4 天 · 上限 8 · 下限 4」。
- 格子:你的畫休、主要分店那天的同日畫休人數「2/2」;點 ⓘ 看那天誰畫休、涉及哪些規則。
- 違規清單:列出違反的規則,按 [查看] 看那一天的詳細。
- 違反**限制**的畫休不會存進去,畫面會告訴你原因;違反**提醒**照樣存,但會列在違規清單。
- 開放期間外不能自己修改;要調整請聯絡店長或排班負責人(有代改權限的人會看到「到畫休總覽代改」)。

## 重要規則

- 只顯示**已發布**的班;還沒發布的月份員工看不到。
- 畫休只能在畫休開放期間登記**下個月**的;期間外要調整請聯絡店長或排班負責人。

## 圖例

- **負責人底色**:你擔任負責人的班套綠色底。
- **畫休**:格子寫「畫休」;時段不可排寫「09:00–13:00 不可排」。你有畫休的日子整格灰色斜線底。
- **2/2**:同日畫休人數 / 上限;未滿灰色、滿了橘色、超過紅色。
- **色帶**:違反規則的日子底部的色帶,紅色 = 違反限制、橘色 = 提醒。
- **ⓘ**:看當天誰畫休。
- **特殊日**:行事曆設定的顏色當背景,並顯示名稱。
