# 店面管理

## 這個模組做什麼

店裡每天收錢、賣刮刮樂的地方。**看板**列出這家店每個收銀點:哪些開班中、誰負責、本班賣了多少、抽屜裡現在應該有多少現金,以及檯面上每一本刮刮樂還剩幾張。盤點紀錄分頁列出這家店的盤點;撤銷售出、現金更正分頁列出這家店的撤銷售出申請與現金更正單;其他申請分頁列出綁在店面管理的其他表單。你只看得到有權限的分頁,只剩一個時不會出現分頁。

## 常用操作

- **選分店**:頂部的分店選擇器換分店;看板會跟著其他裝置即時更新,不必重新整理。分店選擇器旁的小圓點是綠色表示即時,黃色表示正在重新連線(每 60 秒更新一次)。
- **設定本機收銀點**:每台裝置要先設定自己是哪一個收銀點(頂部「本機收銀點」)。設定存在這台瀏覽器,不跟帳號走;換一台裝置要重新設定。沒有設定時刷到刮刮樂只會顯示資訊,不能銷售、兌獎。
- **開班**:在未開班的收銀點按「開班」。
  - **期初零用金**:這個收銀點的第一班(從來沒開過班,或上一班已經日結)可以填「從小金庫領零用金」,開班時會同時記一筆出庫(原因「開班零用金」),沒領就是 0;其他班的期初是上一班「留給下一班」的金額,不能改。
  - **對應排班一定要選**:系統會先帶出依時間找到的排班,可以改選你這天在這家店的其他排班;都不是就選「沒有排班(臨時代班)」,這一班會標示「未對應排班」。
  - 選的排班沒有排你在這個收銀點的崗位時,會提醒「你今天排的是…」;只是提醒,照樣可以開班,系統會記下來。
  - 還沒打上班卡時會出現「你還沒打上班卡」,按「打卡」直接打這一班的上班卡。
- **班次資訊與改對應排班**:點收銀點名稱下方「負責人 …」那一行,看開班時間、期初零用金、對應排班與任務快照。這一班的負責人或店長在交班結帳送出前可以按「改對應排班」,改的時候原因必填。這裡的「店長」指角色有店面管理「編輯」權限的人;角色權限可以在角色管理調整。
- **投庫 / 出庫**:在本機收銀點按「投庫」(抽屜 → 小金庫)或「出庫」(小金庫 → 抽屜,原因必填,例如補零錢)。做完就生效,不用審核,應有現金馬上更新。
- **兌獎**:在本機收銀點按「兌獎」,刷刮刮樂的**背面編號**,畫面會顯示遊戲、本號、張號與是不是本店的刮刮樂;選常見金額或直接輸入中獎金額,按「確認兌獎」。錢從這個收銀點的抽屜付出,應有現金馬上減少。成功後右下角(手機在底部)出現「已兌獎 RD-0219 · … 撤銷」,打錯了可以直接按「撤銷」。每一筆兌獎紀錄都有單號(RD-0001 起連號),撤銷了也不收回,「撤銷並重新登記」的新紀錄用新的單號;單號顯示在提示、最近兌獎、兌獎紀錄、詳情與進貨單勾選的兌獎紀錄上,加單號之前登記的舊紀錄顯示「—」。
- **最近兌獎**:按標題列的「最近兌獎」看自己在這一班登記的兌獎,每一列可以「撤銷」;點一列看詳情。清單只在按的時候打開,兌獎後不會自動打開。
- **撤銷兌獎**:自己登記、這一班還開著的,自己就能撤銷,不限時間、不用填原因。那一班已經交班結帳、或不是自己登記的,要由有「撤銷兌獎」權限的人(通常是店長)撤銷,原因必填;還可以按「撤銷並重新登記」,撤銷後直接登記正確的那一筆,算在同一班。
- **兌獎紀錄**:「兌獎紀錄」分頁列出這家店的兌獎(第一欄是單號),可以依期間、收銀點、狀態、登記人篩選,也可以輸入單號找某一筆(打「RD-0218」或只打「218」都可以;輸入單號時不限期間,上個月的也找得到);點一列看詳情。
- **同時顧兩個收銀點**:你可以同時開同一家店多個收銀點的班。頂部會顯示「你開著的班」;另一班的收銀點會出現「切換到這個收銀點」,切換後之後的兌獎、投庫、出庫都算到那個收銀點。
- **賣刮刮樂**:在本機收銀點用條碼槍刷條碼(手機、平板可以按頂部「📷 掃描」用相機連續掃),刷到放在本機收銀點的刮刮樂就直接售出,右下角(手機在底部)出現「已售出 … 撤銷」。在其他頁面刷到刮刮樂時會跳出「快速銷售」小視窗,按 Enter 確認、Esc 取消。
  - 刷到放在別的收銀點的刮刮樂:那一班是你開的 → 確認後直接算那一班;別人的班 → 確認後會寫「移櫃」再「售出」,錢算你這一班。沒有移櫃權限時不能這樣賣,請由那個收銀點售出。
  - 同一個本號在本店有兩款遊戲時,會先問你是哪一款。
  - 還沒拆的本會問你要不要拆本並售出;待查的刮刮樂會提示尋回(要有尋回權限,原因必填,尋回後回到這家店的庫存)。已售、跳號、報廢、調貨中或撤銷審核中的刮刮樂不能賣。
- **撤銷剛賣的**:按售出提示的「撤銷」、收銀點的「最近售出」清單,或展開卡片選本班售出的張按「撤銷售出」。只有你自己賣的、30 分鐘內、這一班還開著、那張刮刮樂之後沒有其他異動才能直接撤銷;不然視窗會出現「送撤銷售出申請」,按下去會開撤銷售出申請並帶入那一張。
- **展開卡片**:點檯面上的卡片會在原地展開這本的格子(手機是底部面板),一次只展開一張。選張後依狀態出現按鈕:本機收銀點的未售可以「標記售出」(刷不到條碼時用,原因必選)、「移櫃」、「收回」;其他收銀點的未售可以「移櫃」或「移櫃並售出」。刷條碼時,刷到的那一格會閃一下。
- **拆本**:在本機收銀點按「拆本」,選本店還沒拆的本(也可以刷條碼)。迄號比標準張數多時,要先在格子點出不存在的號碼(跳號),點滿才能下一步;再選全部放到一個收銀點,或分放到多個收銀點(每一張都分完才能確認)。跳號的張不算庫存。拆本時分放到多個收銀點不需要移櫃權限。
- **撤銷售出申請**:在「撤銷售出」分頁按「新增」(或從撤銷確認視窗的「送撤銷售出申請」進來)。刷條碼加入要撤銷的張,同一本的張放在同一組格子裡,也可以直接在格子點選;只能選本店已售、不在其他撤銷售出申請上的張。選原因後會自動帶入「退款給客人」(客人退貨 = 是,其他 = 否),可以改;退款給客人時要選退款班次,預設是你目前開著的班。退款金額是這些張的面額合計。送出後這些張會標示「撤銷審核中」、不能再賣,店長核准後張改回未售、回到原來的收銀點,退款記在退款班次;被駁回什麼都不記。
- **現金更正單**:抽屜或小金庫的錢和系統對不上時,在「現金更正」分頁按「新增」:方向(現金增加 / 現金減少)、金額、位置(某一班的抽屜或小金庫;關店後發現的錢一律選小金庫)、歸屬班次(選填,表示是誰的責任,可以選已結帳的班)、原因類別與說明。店長核准後才記到那一班或小金庫的應有現金;被駁回什麼都不記。
- **移櫃、收回**:在展開的卡片選張按「移櫃」(換到別的收銀點)或「收回」(回到庫存),可以選全部或只動選到的張。一律留下紀錄,不需要審核。

- **盤點**:按頂部的「盤點」,選全店或單一收銀點後開始。距離上次盤點超過 24 小時,看板頂部會提醒「建議盤點一次」。
  - 左邊是要盤的本(依收銀點分組,手機在上方的下拉),每本標示已盤、未盤或差異幾張。選一本後,在格子點出**實際還在檯面上**的張(已選 = 在),也可以切到「掃描」用條碼槍一張一張刷;盤點時刷到的刮刮樂只會記成「在」,不會被當成售出。格子下方的系統數字是你開始盤這一本那一刻的數字,之後客人買走的不算差異。
  - 全店盤點還要確認「未拆的本」在不在(不在的本盤點完成時列為待查),以及處理「待查清單」:找到了(要刷條碼:整本都待查的刷到任一張就算整本找到;零碎的只有刷到的張算找到,沒刷到的維持待查)、確認遺失(要有權限,原因必填)或繼續待查。
  - 每個收銀點旁有那個收銀點目前的應有現金與「補登兌獎」,補登兌獎**立即生效**,和看板上的兌獎一樣;那個收銀點沒有開著的班時不能補登兌獎。
  - 按「差異核對」逐張處理差異,可以多選後一次套用:系統未售、實際不在 →「補登售出」或「待查」;系統已售、實際還在 →「標記異常」(之後用撤銷售出申請「盤點錯誤」更正);整本盤錯可以「重新盤點這本」。**補登售出立即生效**:那個收銀點有開著的班就算進那一班,已經結帳就記成那個收銀點最近一班的事後更正。
  - 盤點時不鎖:兩個人可以同時盤,一天不限次數。別人已經處理掉的張會提示「這幾張已被處理,請重新核對」,按「重新核對」後再送出。
  - 沒盤完也可以送出:送出前會提醒「還有 N 本沒有盤」。沒盤的本不比對、不算差異,盤點單會記下這幾本(遊戲、本號、收銀點),盤點紀錄標示「N 本未盤」、點進去可以看是哪幾本;之後再開一次盤點把它們盤完就好。
  - 按「送出」確認後送出**盤點確認申請**給店長核准;盤點過程只在畫面上,重新整理或離開就要從頭盤。核准後才會套用待查、確認遺失與找到了;被駁回時已補登的售出不會退。被退回時打開那張申請按「修改後再送出」,會帶入原本的內容。
- **盤點紀錄**:「盤點紀錄」分頁列出這家店的盤點(臨時、交班、日結),可以依類型、狀態篩選;點一列看盤點確認申請的明細與審核。

- **交班結帳**:在本機收銀點按「交班結帳」(只有這一班的負責人或店長看得到),四個步驟一次做完;中途按「取消」或重新整理不會留下任何資料。
  - **① 盤點**:30 分鐘內有盤過這個收銀點(或全店)就可以「沿用」;「現在盤點」只盤這個收銀點,和盤點頁一樣點格子或刷條碼(刷到的刮刮樂只記成「在」,不會被當成售出),差異核對完才能下一步;有跳過盤點權限的人可以「跳過盤點」,原因必填,報表會標示「未盤點」。
  - **② 兌獎**:列出這一班的兌獎;漏登的按「補登兌獎」,**立即生效**(和看板上的兌獎一樣,之後取消精靈也不會退回)。
  - **③ 抽屜**:左邊是系統算的應有現金(期初零用金 + 銷售 − 兌獎 − 投庫 + 出庫 − 調貨支出 + 調貨收入 − 退貨退款 ± 現金更正,只算已完成的單據;每一項可以點開看明細與單據),右邊依面額填清點的張數,系統算出實點與差額;差額不是 0 時原因必填。還在審核中的現金更正單、撤銷售出申請會列在下面,差額原因自動帶入「審核中的單據」。
  - **④ 確認**:填「留給下一班」(不能超過實點,留給下一班的零用金是實點裡的錢)與「接班人」(選填;接班人是下一班的人,不能選自己或這一班的負責人)。留給下一班大於 0 時一定要選接班人;沒有接班人就必須是 0(錢先投庫),這張結帳確認申請改由店長審核。按「送出」就送出**結帳確認申請**,這一班結束,下一班可以先開班(期初就是你填的「留給下一班」)。
  - 有接班人時由接班人審核(當面點過零用金後核准);被退回時打開那張申請按「修改後再送出」,會帶入原本的內容,改了「留給下一班」,已經先開班的下一班期初會跟著更新;改成沿用或跳過盤點時,原本那次「現在盤點」的盤點單就不留了。
- **班次結帳歷史紀錄**:「班次結帳歷史紀錄」分頁列出這家店的結帳確認申請(交班與日結),可以依期間、收銀點、類型、狀態篩選(「待審核」看還沒核准的);點一列看結帳單的明細與審核。

- **上次日結**:看板頂部顯示「上次日結:10/13(已 3 天)」。
- **存銀行**:覺得小金庫的錢太多時,按頂部的「存銀行」(要有存銀行的權限),填金額、選存入帳戶(只列使用組織包含這家分店、使用中的帳戶;只有一個時自動帶入)與備註,按「確認存入」就生效,不用審核。金額**不能超過小金庫目前的應有**;實際的錢比系統多時,請先用現金更正單補登。這家店沒有可用的銀行帳戶時不能存,請先到帳戶管理設定帳戶的使用組織。記錯了請到帳戶管理沖正那筆「存入」,小金庫會自動加回來。
- **日結**:按頂部的「日結」(要有結帳與日結的權限),五個步驟一次做完;中途按「取消」或重新整理不會留下任何資料。
  - **這家店所有收銀點的班都已送出交班結帳**才能按;還有班沒交班時「日結」是灰的,滑過去會列出還沒交班的收銀點。已經有一張日結在審核中(或被退回待修改)時也不能再送一張。
  - 頁面上方顯示**涵蓋計算期間**:上一次日結送出到現在,例如「10/14 09:02 ~ 現在(10/14、10/15 沒有日結)」。**不能補日結**:中間漏掉的日子這一次會一起涵蓋計算;每一班只會被一張日結涵蓋計算,日結送出後才送出交班結帳的班算下一次日結。
  - **① 各班結帳**:列出這段期間每一班的交班結帳(收銀點、交班人、送出時間、應有、實點、差額、審核者、狀態)。審核者是你的那一列有「審核」,在側邊打開結帳單直接核准或退回,不用離開日結;別人審的顯示「等某某核准」,被退回的顯示「待某某更正」。狀態會即時更新,**全部核准後**才能下一步。
  - **② 全店盤點**:30 分鐘內有盤過全店就可以「沿用」;「現在盤點」盤全店每個收銀點;有跳過盤點權限的人可以「跳過盤點」,原因必填,報表會標示「未盤點」。
  - **③ 小金庫**:左邊是小金庫應有(期初是上一次日結清點的金額 + 投庫 − 出庫 ± 調貨 ± 現金更正 − 存銀行,每一項可以點開看明細),右邊依面額清點;差額不是 0 時原因必填。
  - **④ 存入銀行**:要順便存銀行就填金額與帳戶(不存就填 0),金額不能超過小金庫清點的錢;畫面會算出存入後小金庫的應有。
  - **⑤ 確認**:看過涵蓋計算期間、全店盤點、各班差額合計、小金庫差額與存入銀行後,按「送出結帳確認申請」,由店長審核。
  - **核准完成時**:小金庫從這次清點的金額重新起算;有填存入銀行的,這時才記一筆「存銀行」並在那個帳戶記一筆「存入」(兩邊是同一筆);全店盤點也在這時套用。被退回時打開那張申請按「修改後再送出」,會帶入原本的內容,涵蓋計算期間照原本送出時的那一段。
- **日結逾期**:有已送出交班結帳的班還沒被日結涵蓋計算,而且已經過了送出日隔天的提醒時間(預設 09:00),店長會每天收到一則「日結逾期」提醒,側欄「店面管理」旁的數字也會加 1,直到日結送出為止。提醒時間可以在通知設定頁調整。

## 重要規則

- 一個收銀點同時只能有一班;兩個人同時按「開班」,只有先送出的那一位會成功。
- 一個人可以同時開同一家店多個收銀點的班,但**不能同時開兩家店的班**。
- 開班的人就是這一班的負責人。
- **投庫的金額不能超過抽屜目前的應有現金**。
- **出庫(含開班時從小金庫領零用金)的金額不能超過小金庫目前的應有現金**。小金庫實際的錢比系統多時,請先用現金更正單登記。
- 應有現金完全由紀錄算出:期初零用金 + 售出 − 撤銷 − 兌獎 − 投庫 + 出庫 − 退貨退款 ± 現金更正(之後還會加上調貨)。
- **單張中獎超過 5,000 元不能在店裡兌**,請客人到銀行兌獎;兌獎金額也不能超過抽屜目前的應有現金。
- **同一張刮刮樂不能兌兩次**(別家店兌過也一樣);撤銷之後才能重新登記。
- **兌獎紀錄的狀態**:店內持有(還在店裡)、已送兌(已勾進進貨單拿去兌獎)、已撤銷。**已送兌的不能撤銷**,要先撤回或退回那張進貨單,回到店內持有後再撤銷。
- **事後更正**:那一班已經交班結帳之後才撤銷或重新登記的兌獎,會記成那一班的「事後更正」,不改已送出的結帳單,下一班的期初也不變;報表會在那一班列出。
- **交班結帳送出後這一班就結束**:不能再銷售、兌獎、投庫、出庫;同一個收銀點可以馬上開下一班。一班同時只能有一張審核中的結帳確認申請。
- **結帳確認申請不能駁回、不能作廢**,只能退回修改。
- **存銀行的金額不能超過小金庫目前的應有現金**;日結時存入銀行的金額不能超過小金庫清點的錢。
- **日結送出後、核准前,要存入銀行的錢先保留**:出庫、開班領零用金與存銀行都不能動用這筆錢(例:小金庫應有 9,000、日結要存 5,000 還在審核 → 最多只能再拿 4,000)。核准前存入帳戶被停用,這張日結照樣存入。
- **日結要等這家店所有的班都交班、涵蓋的交班結帳全部核准**,送出時系統會再檢查一次。
- 撤銷售出申請與現金更正單**沒有草稿**,送出就進審核;店長自己送的會自動通過。**核准完成後不能作廢**,記錯了請再開一張反向的。
- 撤銷售出申請、現金更正單完成時,如果那一班已經交班結帳,錢會記成那一班的**事後更正**:結帳單不會改,下一班的期初也不變,只是補上那一班差額的原因。
- 已經被開班選用的排班,在排班作業不能刪除;要調整請改時間。
- **同一張刮刮樂兩個人同時刷,只有一個人賣得出去**;另一個人會看到「這張刮刮樂已於 hh:mm 售出」。
- 售出的錢算進那一班的應有現金;撤銷就扣回來。
- **看得到的按鈕就是你做得了的事**:沒有「開班」「兌獎」「投庫」「出庫」「拆本」「移櫃」「收回」「標記售出」「撤銷」「存銀行」「日結」或撤銷兌獎的按鈕,代表你沒有那個權限,需要時請洽系統管理員。
- 盤點確認申請**不能作廢**;待查的張之後刷到時再尋回。
