# 表單管理

## 這個模組做什麼

設計各模組要填寫的**表單**:欄位、版面、版本,以及表單在你的組織裡開不開放填寫。畫面左側是表單清單,右側是選中表單的「表單設計」與「表單版本」兩個頁籤。

表單分兩種:

- **共用表單**:由系統管理員建立並提供給你的組織。你可以看、可以開關,但不能直接改它的欄位。
- **自己的表單**:以某張共用表單的某一版為基底建出來、只有你的組織看得到。欄位、版本都由你管理。

## 常用操作

- **以此為基底建新表單**:在右側標頭按這個按鈕,選一個基底版本,填**表單 key** 與名稱。表單 key **建立後不能修改**(只能用小寫英文開頭、小寫英文 / 數字 / 底線)。建好後會帶著一份草稿,可以直接開始改。
- **表單設計**:
  - 從「元件」面板把欄位型別拖到畫布上(或直接點一下加在最後),畫布上的欄位可以拖拉調整順序與分區。
  - 點選畫布上的欄位,在右側的屬性面板改顯示名稱、元件、寬度、必填、選項、公式、顯示條件、鎖定條件等;每種欄位只會出現它用得到的設定(例如上傳與引用欄位沒有「值的來源」)。是否欄位設成必填,代表填寫的人一定要勾選。
  - 改**欄位 key** 時,格式不對或和別的欄位重複會立刻標紅,不會寫進去。
  - 公式與條件用選單組出來,不用自己打字;每一格只列型別對得上的欄位、系統值(現在時間、時區、填寫者、填寫者的目前組織、填寫者所屬的組織(全部)、最上層組織)、常數與運算。條件一定要組成「是 / 否」的判斷,不能只放一個常數。還沒選的格子顯示「請選節點種類」;「且」「或」底下按「+ 條件」再加一個判斷,新加的判斷預設是「等於」。一層運算包在一個框裡,框的標題是那個運算的名稱。下方的「JSON 預覽」可以複製。
  - **鎖定條件(成立時此欄位不可修改)**:條件成立時這一欄變成唯讀。**自訂驗證(條件成立才通過)**:條件不成立就擋下送出,並顯示你填的**錯誤訊息**。
  - 選項來源的類別、來源表單與它的欄位都從下拉挑:來源表單只列看得到且已經發布過的。
  - 計算與固定值欄位在畫布與填寫頁顯示成唯讀的框,不能直接改。**固定值**依欄位型別輸入:是否選是或否、日期用日期選擇器、單選 / 多選從選項裡挑。
  - **單選 / 多選的公式**要算出一個選項:最外層只能放「如果…則…否則」、選項相同的其他單選 / 多選欄位,或直接從這一欄的選項挑一個(多選可挑多個);「然後 / 否則」也一樣。不能用串接文字或選項顯示名。
  - **預設值**(值的來源是「使用者填」才有):新增時自動填入。文字、數字、日期、日期時間可以設固定值或公式;單選 / 多選從選項裡挑(選項來自欄位管理類別或資料來源時,先存草稿才挑得到);是否設是或否;引用只能選「填寫者」或「填寫者的組織」。填寫的人還沒改過這一欄前,公式用到的欄位變了會跟著重算;改過就不再變。
  - **日期**與**日期時間**欄以你的組織的時區輸入與顯示(日期顯示成「年-月-日」,日期時間再加上「時:分」);日期時間的上下限用日期時間選擇器挑。公式的「日期差」可以選天、小時或分鐘:天是依日曆算的天數,小時 / 分鐘是精確的時間差。「日期加減」從一個日期往前(之前)或往後(之後)算幾天、幾週、幾個月或幾年,例如「付款日之後 30 天」;加到月底放不下時取那個月的最後一天。日期和日期時間可以直接比較,比的是哪一天(例如付款日等於現在時間 = 付款日是今天)。常數也可以選日期或日期時間,用選擇器挑。
  - **上傳**欄可以在驗證規則裡限制**允許的檔型**與**大小上限(MB)**;不設就是系統允許的全部檔型、20 MB。
  - **明細列**:一個欄位裡放好幾列同樣格式的資料(採購品項、出差行程、加班時段),填寫時是一張表格。從「元件」面板加進來後固定占滿整列,屬性面板多一塊「**子欄位**」:清單列出每個子欄位的 key、標題、型別、必填與寬度,點一個子欄位就打開它自己的設定(只有標題、型別、小數位數、表格欄寬、說明、值的來源、選項、驗證規則),按「← 回子欄位清單」回來。子欄位可以是文字、數字、日期、日期時間、單選(靜態清單或欄位管理類別)或是否;同一個明細裡的子欄位 key 不能重複。一張表單最多 5 個明細列、每個明細最多 20 個子欄位。
  - 明細列的**必填**是「至少要有一列」;另外可以設**最少列數**與**最多列數**(沒設最多就是 100 列,最多 200 列)。
  - **列內公式**:子欄位的值的來源選「列內公式」,可以用同一列的其他子欄位(選單上標「本列・」),例如小計 = 本列・數量 × 本列・單價;也可以用表單上的其他欄位,例如小計 × 折扣率。
  - **彙總**:表單上的公式與條件可以用「明細加總 / 明細筆數 / 明細最小 / 明細最大 / 明細平均」,先挑明細欄、再挑要算的數字子欄位(筆數只要挑明細欄),例如總價 = 明細加總(品項, 小計)。沒填的格子不算;明細被隱藏或一列都沒有時,加總與筆數是 0,最小 / 最大 / 平均是空的。每一列的小計照它的小數位數取好再加總,和畫面上看到的一致。
  - 明細列本身不能當摘要、列表欄位或帶入的目標;要把合計放進摘要,就用彙總做一個計算欄位再對它。
  - 沒有選欄位時,右側是「表單設定」:指定摘要的**標題**(必填)、日期、金額,以及帶入資料的規則。
  - 帶入規則照填寫時的順序設定:**規則名稱**(填寫時「帶入資料」跳窗的來源清單顯示它)→ 來源(使用者 / 組織 / 表單提交,或其他可用的資料來源)→ 表單 → 顯示欄 → 顯示模板(選填)→ 固定條件(選填)→ **對應表**(每一列「本表單欄位 ← 來源欄位」,來源欄位只列型別合得上的)。表單可以選這張表單自己(從之前填過的單帶入,例如沿用上一張的收件地址),還沒發布也可以選,來源欄位就是目前正在設計的欄位。
  - 資料來源(選項、引用欄位、帶入規則)都可以設**顯示模板**,決定選資料時每一筆怎麼顯示,例如 `{{name}}({{email}})` 顯示成「王小明(wang@example.com)」。用「插入欄位」下拉挑欄位插入,不必手打;來源是表單提交時,摘要是 `{{title}}`、`{{date}}`、`{{amount}}`,其他欄位的寫法由「插入欄位」下拉自動帶入。日期依你的組織的時區顯示,選項顯示名稱。沒有權限讀到模板裡某個欄位的人,只會看到顯示欄的值。不填就用顯示欄。
  - 「檢查結果」列出目前的錯誤與警告,點一下會帶你到出問題的欄位。有錯誤不能發布,警告可以。
  - 按「預覽」切換成填寫的樣子,輸入測試值看條件與公式的結果(不會建立任何資料)。
  - 改完按「存草稿」。
- **表單版本**:
  - 草稿那一列按「發布」,填**變更說明**(必填)後送出;發布後所有人新增時都用這一版。
  - 「退役目前版本」:之後這張表單不能再新增,直到再發布一個新版本;既有資料照常可以看。
  - 任何一個版本都可以按「以 v幾 為基底開新草稿」(已經有草稿時要先發布或刪除那份草稿),也可以看它「與上一版差異」。
  - 草稿那一列按「**刪除草稿**」,確認後草稿與還沒存的變更都會丟掉;已發布的版本不受影響,之後可以再以任一版本為基底開新草稿。發布進行中不能刪。
  - 已發布或已退役的版本按「檢視」,會在「表單設計」頁籤以**唯讀**打開那一版:看得到欄位與標示、可以切「預覽」試填,但不能修改、不能存;旁邊有「以這一版為基底開新草稿」的按鈕。按「關閉檢視」回到草稿。
  - **將舊版資料升級到此版**:已發布的版本那一列有這個按鈕,把你的組織裡還綁在舊版本的資料(草稿與已完成)改成用這一版。需要這張表單所屬模組的「編輯」權限;表單綁了審核流程時不能升級,版本清單上方會有一行提示。
    1. 第一步列出各舊版本各有幾筆要升級,以及可以**補值**的欄位(這一版的必填欄位、摘要用到的欄位、這一版新增的欄位)。補值的輸入框依欄位型別呈現:單選是下拉、多選可以挑多個、日期用日期選擇器。補的值只會填進「那一筆沒有值」的欄位,已經有值的不會被蓋掉;可以留空。明細列、上傳、引用欄位不能補值。
    2. 第二步確認要升級的筆數與補值。
    3. 第三步顯示結果:各舊版本升級了幾筆、跳過幾筆與原因(例如升級時正好有人在改那一筆)。跳過的可以之後再升級一次,已經是這一版的不會重複處理。
  - 升級會重算計算欄位與摘要,舊版本有、這一版沒有的欄位會拿掉(修訂紀錄裡的舊內容仍然留著);已完成的資料會多一筆修訂紀錄,寫明誰在什麼時候升級到第幾版。公式裡用到「現在時間」或「填寫者」的欄位,升級時照那一筆原本的填寫時間與填寫者算,不會變成升級的人與升級當下。**升級不檢查必填與格式**:不符合新版規則的資料,下次有人編輯送出時才會被要求補齊。
  - **匯出專案設定**(只有系統管理員在共用表單目前發布的版本上看得到):把這一版的設計下載成一個設定檔,交給開發人員放進專案,其他環境就會有同一份表單。
    1. 填**版本識別**(小寫英文或數字開頭,可用小寫英文、數字、底線、連字號,最長 64 個字)與**發布說明**,按「下載設定檔」。每次修正後重新匯出,都要換一個新的版本識別。
    2. 只匯出這一版的設計內容,不會更動任何資料;人員、組織、表單提供給哪些組織、流程綁定都不會被帶走。
    3. 這一版用到只在目前環境才有的資料時(例如預設值指定了某一位使用者、選項來自自行新增的類別、帶入來源是某個組織自己的表單),不會下載,畫面會列出是哪個欄位與原因。請以這一版為基底開新草稿、修正後發布,再匯出新的版本。
- **編輯名稱與標題**:頁籤 / 標題模板決定每一筆資料打開時頁籤與標題顯示什麼,可以用的佔位符列在輸入框下方:

  | 佔位符                                | 顯示                                                             |
  | ------------------------------------- | ---------------------------------------------------------------- |
  | `{{title}}`、`{{date}}`、`{{amount}}` | 摘要的標題 / 日期 / 金額                                         |
  | (用下拉插入)                          | 某個欄位的值:用「插入欄位的值」下拉挑欄位,會自動插入正確的寫法   |
  | `{{applicant}}`                       | 建立者(顯示現在的名字)                                           |
  | `{{form}}`、`{{module}}`              | 表單名稱、模組名稱                                               |
  | `{{action}}`                          | 檢視 / 編輯 / 新增;沒寫時會自動加在最前面,例如「檢視・病假申請」 |

  標題跟著填寫的內容即時變化,草稿也看得到;日期依你的組織的時區顯示,選項顯示名稱。模板下方會即時顯示用範例資料套出來的樣子。

- **在本組織啟用**:右側標頭的開關決定這張表單在你的組織開不開放新增;關掉只擋新增,不影響既有資料。
- **允許存草稿**:右側標頭的開關決定填寫的人能不能先「存草稿」。關掉後,新增與編輯頁不會出現「存草稿」,只能填好直接送出;已經存好的草稿照樣可以打開、送出或刪除,只是不能再存草稿。被退回或撤回的單也只能改好重新送出。「複製為新單」不受影響。共用表單由系統管理員設定,你看得到目前的設定但不能切換;自己的表單由你設定。
- **作廢原因**:「單號」下方的「作廢原因」可以選一個欄位管理的類別。選了之後,作廢這張表單的單時要從該類別的選項挑原因,挑「其他」(選項值為 other 的那一個)還要寫說明;不設定就是作廢時自由填寫理由。選項在「欄位管理」維護,各組織看得到的選項和欄位管理一樣(共用的 + 上層組織的 + 自己的)。共用表單由系統管理員設定,你看得到目前的設定但不能改。
- **依欄位共用**:「作廢原因」下方的「依欄位共用」列出表單裡選組織的欄位(例:收貨組織)。勾了之後,單據送出後,看得到這個欄位選到的組織的人(那個組織的人,以及看得到它的上層組織的人)也看得到這張單,但只能看、不能修改或刪除;草稿不會給別人看。不勾就只有看得到單據所屬組織的人看得到。共用表單由系統管理員設定,你看得到目前的設定但不能改。
- **單號**:打開「第一次送出時給單號」,填前綴、流水號多久重新起算(不重新起算 / 每年 / 每月)、位數與分隔符,下方會顯示例子,按「儲存單號格式」才生效。之後每張單**第一次送出**時給一個單號(存草稿不給);給了就不會變,退回修改、撤回、作廢都保留原號,「複製為新單」的新單送出時另給。每個最上層組織(連同底下的分店)各自從 1 開始。關掉開關就不再給號,已經給的保留。共用表單由系統管理員設定,你看得到目前的設定但不能改。
- **流程綁定**:右側標頭下的「送出後走的審核流程」決定這張表單送出後要不要審核、走哪個流程(流程在「流程管理」設計)。
  - 下拉只列**可以直接綁**的流程;選「不走流程」就是送出即完成。一張表單只能綁一個流程,好幾張表單可以綁同一個。
  - 不能直接綁的流程會列在下方並寫原因(第幾關、什麼問題)。共用流程裡的角色只有名稱、沒有對到你組織的角色時,按「建客製流程」到流程管理以它為基底建一個自己的,選好角色、發布後再回來綁。
  - 改成「不走流程」前會先提醒:**已經進過審核的單(例如被退回修改的)再送出會被擋下**。
  - 清單上標「綁定的流程已失效」表示綁的流程已經不能用了,這張表單現在送不出去,請換一個流程或改成不走流程。

## 重要規則

- **刪除欄位只動草稿**:刪之前會列出哪些公式、條件、摘要或帶入規則還用到它;刪掉後那些地方會在「檢查結果」變成錯誤,要你自己改,系統不會自動幫你改。刪除分區時可以選「欄位移到未放置區」或「連同欄位一起刪除」。
- **已發布的版本不會變**:要改就開新草稿、再發布一版;已經填好的資料照它當時的版本顯示。
- **沒有「刪除表單」**:表單與它的各個版本會一直保留(已填好的資料要靠它們顯示);只有還沒發布的設計草稿可以刪。不想再讓人新增,就「退役目前版本」,或關掉「在本組織啟用」。
- **共用表單沒有全體共用的「啟用」開關**:系統管理員要停用一張共用表單,做法是退役它的目前版本,或收回提供給你的組織;「在本組織啟用」是你的組織自己的開關,只影響你的組織。
- **「草稿已被別人更新,請重新載入」**:有人同時在改同一份草稿,後存的人會被擋下。重新載入後再改。
- **受保護欄位**:欄位設成「受保護」或「限定可改」時,發布後會多出對應的權限,要在角色管理授予才看得到 / 改得動。
- 共用表單的建立與提供給各組織,由系統管理員處理;需要新的共用表單請聯絡系統管理員。
