# 總覽

## 這個模組做什麼

登入後看到的第一頁,之後會在這裡集中顯示你的組織最常用的資訊(統計、最近的項目、公告)。目前先顯示你的名稱與當前組織。

## 重要規則

- 總覽和其他頁面一樣由角色授權;角色沒有「總覽」時,登入後會直接進入選單裡第一個可用的頁面。
- 頁面內容之後會依模組逐步加入;想調整可用的區塊,請聯絡系統管理員。

## 頁籤與選單

- 開過的頁面會在上方的頁籤列各留一個頁籤:點頁籤切回那一頁,按頁籤上的 × 關閉,也可以拖曳調整順序。
- 在頁籤上按滑鼠右鍵(手機、平板按住頁籤約半秒不動),或按頁籤列最右邊的「⋯」,可以一次「關閉左側所有分頁」「關閉右側所有分頁」「關閉其他所有分頁」;「⋯」作用在目前這一頁。沒有可關的頁籤時,那一項是灰的。
- 正在看的頁面沒被關掉時畫面不動;被關掉時會切到你按右鍵或長按的那一頁。
- 手機與直拿的平板上,左側選單平常收起來,按畫面左上角的選單鈕打開,點了頁面後會自動收起。
- 手機與直拿的平板上方只留選單鈕、頁面名稱、通知與組織切換(顯示目前組織名稱的第一個字,點了可換組織);頁面說明「?」與你的帳號選單(個人設定、外觀、語言、登出)在左側選單的最下方。
