# 角色管理

## 這個模組做什麼

角色是一組權限的集合,由單一組織擁有並自行管理;把角色授予使用者,他就取得對應的功能。左邊挑一個角色,右邊就是它的「權限設定」與「分配使用者」兩個分頁。

清單上的每個角色都會標出它的**所屬組織**,同名的角色靠這一段分辨;管得到多個頂層組織時,清單還會依頂層組織分組。清單上方有**「依擁有組織篩選」下拉**與**搜尋框**,兩者可以一起用:下拉只留所屬組織正好是它的角色(不含下層組織的角色),搜尋再比對名稱與描述。

## 常用操作

- **新增角色**(清單上方的「+ 新增」):選擇所屬組織(預設帶入你目前所在的組織,只能挑你管得到的),再填名稱與描述。所屬組織就是這個角色的管轄範圍 — **持有者可以管理該組織與它底下的所有組織**;要不同範圍就另外建一個角色,建立後不能再改。
- **編輯角色**:改名稱與描述。
- **權限設定**:逐項勾選,或勾「全部(\*)」— 涵蓋**該模組自己這一層**現有及未來新增的權限;下層模組要另外勾它們自己的「全部(\*)」,或用最上層那一列旁邊的「全選整組」一次勾完整棵。粗體是模組(勾起來 = 這個角色進得去那一頁),縮排的是那一頁裡的權限。改完要按「儲存變更」才算數;還沒儲存就想離開時會先問你一次。
- **分配使用者**:僅能選擇此角色所屬組織**或其下層組織**的使用者。挑人的欄位**直接輸入姓名或 Email 就會即時篩出候選**,選中的人會變成一個個小標籤,點標籤上的「×」就能移掉。不在這個範圍內的人**還是會列出來,但選不動**,那一列底下會寫明原因;要讓他能被加入,請先到使用者管理把他加進對應的組織。挑人的清單**只需要你有分配使用者的權限**,不必另外要使用者管理的檢視權限;**已經持有這個角色的人不會再出現在清單上**。加入是逐筆累加,重複加入同一個人不會出錯。
- **停用 / 啟用**:見下方「重要規則」。
- **刪除**:見下方「重要規則」。

## 重要規則

- 你只能下放**自己擁有**的權限;清單上沒出現的模組與權限,就是你自己也沒有、因此下放不了的。下放後即使你失去該權限,已授出的不會自動收回。
- **勾了下層,上層會自動跟著勾**(不然進不去那一頁);反過來,上層只要還有下層被勾著就不能取消 — 想整棵收掉請用「清空整組」,或先取消下層。
- 「全部(\*)」與同層的個別權限**互斥連動**:勾了「全部(\*)」,同層每一筆都會跟著勾起來(含日後新增的);取消其中任何一筆,「全部(\*)」就會解除,改成保留其餘個別筆。
- **停用**角色:持有者的這個角色立刻失效(他馬上少掉這個角色帶來的頁面與功能),但授予關係還在,之後隨時可以再啟用。停用不會改變任何人的所屬組織。
- **不能停用你自己正持有的角色**:停得掉的話你會立刻失去這一頁,也就沒有任何入口能把它開回來。要停用它,請先把自己從那個角色移除,或請另一位管理員操作。
- **刪除**角色要同時滿足四個條件:①目前沒有任何人持有它 ②不是系統內建角色 ③不是系統在開通時幫你準備好的角色 ④沒有被任何設定的人員條件用到。任一條不符就刪不掉,視窗會逐項告訴你原因;這種時候也可以改用「停用」。
- 被人員條件用到時,視窗會逐項列出是哪個設定、以及怎麼處理:
  - **通知設定的收件人**:到「通知設定」把收件人改成其他角色。
  - **流程的審核者、知會對象或逾時提醒的通知對象**(草稿或目前版本):到「流程管理」修改那一關並發布。
  - **進行中的單據**:還有單據用著舊的流程設定,而那一關用了這個角色。等這些單據完成,或撤回 / 作廢後再刪除;視窗會告訴你有幾張。
  - **資料範圍**:由系統管理員設定,請聯絡系統管理員修改。
  - 有那一頁的編輯權限時,頁名會是連結,點了直接過去。
- **系統開通時幫你準備好的角色**(清單上標示「預設角色」):名稱與描述你改得動,但**權限只能縮不能擴** — 畫面上它目前沒有的項目會是不可勾選的灰色,要更大的範圍請聯絡系統管理員;這種角色也**不能停用、不能刪除**,它是你這個組織的根本角色。這類角色的可勾選範圍還有一個**上限**:系統內建的角色範本。範本沒有包含的項目一律是灰色的,即使系統管理員也不能在這裡把它打開 — 那要由系統版本更新來調整範本。
- **系統內建角色**(標示「系統內建」)不能改名、不能停用、不能刪除,權限設定只能看不能改 — 它的內容隨系統版本更新。
- 一列上沒出現的動作,代表這個角色依規則不給做(或你沒有那個權限);不是畫面漏了。
- 授予角色**不會**改變使用者的所屬組織。
- 分配使用者清單上的「組織外」表示:這個人不在該角色的所屬組織或其下層組織內(多半是他後來被移出了那個組織)。權限照常有效,只是他看得到的資料仍以自己的所屬組織為準;要收回就用「移除」。
- 頂層組織的擁有者受保護:他的管理員角色不能被解除,那一列的「移除」是停用狀態。
- 每一次建立、編輯、權限調整、停用、刪除與授予變更都會留下紀錄。
