# 個人設定

## 這個頁面做什麼

調整只跟你自己有關的設定。從右上角的頭像選單點「個人設定」開啟,每個登入的人都能使用,不需要另外開權限。

## 常用操作

- **偏好**:跟著你的帳號走的個人偏好,換一台電腦登入也一樣。
- **代理人**:請假或出差時,按「新增代理」選一位同事、開始與結束日期。代理期間內輪到你審核的單據,會改派給代理人審核,審核歷程寫「由代理人代理你」。

## 代理人的規則

- 只能設定自己的代理;代理人要是同一個最上層組織裡、啟用中的人,不能是你自己。
- 同一段時間只能有一位代理人,新增的期間不能和已設定的重疊。
- 只有**代理期間內新派出**的審核才交給代理人;代理開始前已經派給你的,仍在你名下。刪除代理後,已經交給代理人的也不會轉回來。
- 申請人是代理人自己的單據,仍由你審核(避免自己審自己)。
- 代理人在派任當下已停用或不在同一個最上層組織時,照常派給你。
- 代理人自己也設了代理時,仍交給你的代理人,不再往下轉。
- 同一關有好幾位審核者都委託同一位代理人時,代理人在這一關只審一次,這一次的核准、駁回或退回修改就算所有委託他的人的意見;審核歷程寫「由代理人代理 甲、乙 核准」。
- 你的代理人本來就是同一關的審核者時,他只審一次,這一票也算你的。
- 代理設定後不能修改。要提早結束請刪除這筆代理;要延長或改期間,請刪除後重新設定。
- 已結束的代理保留紀錄,不能修改或刪除。

## 重要規則

- **語言**與**外觀**在右上角的頭像選單切換,切了立刻生效,不在這一頁。
- 語言跟著帳號:在一台電腦切換後,到另一台電腦登入也會是同一種語言。外觀只記在這台電腦的瀏覽器。
- 畫面的顯示密度固定,不提供個人調整。
