# 輸出報表

## 這個模組做什麼

選一張報表,設定期間與組織,先在畫面上預覽,或直接匯出成 Excel。

畫面左邊是「報表」選單,只列出你有權限的報表;右邊是那張報表的條件。

## 常用操作

- **選期間**:
  - **日**:選一個日期,或按 [今天] [昨天]。
  - **週**:在月曆上點任一天,就會選到那一整週(一週從星期日開始),下方顯示這週的起訖;也可以按 [本週] [上週]。
  - **月**:點月份格子,或按 [本月] [上月];用左右箭頭換年份。
  - 有些報表只提供其中幾種期間,只有一種時不顯示切換。
- **選組織**:可以選多個,每張報表有上限(寫在報表名稱後面),到了上限就不能再勾。
- **其他條件**:有些報表另有勾選或下拉,會出現在期間下方。
- **預覽**:按 [預覽] 在畫面上看報表,內容和匯出的 Excel 一樣。上方的頁籤可以切換「全部組織合計」與各組織,一開始顯示合計。用手機看時,表格的每一列會變成一張卡片。按 [返回條件] 回去改條件。
- **匯出 Excel**:按 [匯出 Excel] 下載。檔案裡每個組織一個工作表,再加一個「全部組織合計」;已設定好 A4、一頁寬、每頁重複最上面的說明列,直接列印即可。

## 重要規則

- 期間都以本公司所在地的日期計算,與你電腦的時區無關。週一律從星期日開始;沒有自訂起訖。
- 沒有選組織時不能預覽或匯出。
- 期間或組織數超過報表的上限時,會提示你縮小範圍。
- 選單是空的,代表你目前沒有任何報表的權限;看不到 [匯出 Excel],代表你沒有匯出的權限。需要的話請洽系統管理員。
- 改了條件之後要重新按 [預覽],畫面才會換成新的結果。
