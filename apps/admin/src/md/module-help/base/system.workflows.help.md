# 流程管理

## 這個模組做什麼

設計表單送出後的**審核流程**:要經過哪幾關、每一關誰審、幾個人要過、什麼情況可以跳過。流程設計好、發布後,到「表單管理」把表單綁上流程,這張表單送出後就會開始審核。

畫面左側是流程清單,右側是選中流程的「流程設計」與「流程版本」兩個頁籤。流程分兩種:

- **共用流程**(清單上標「共用」):由系統管理員提供給你的組織。你可以看,但不能直接改;要調整就「以此為基底建流程」。
- **客製流程**(清單上標「客製」):你自己建立,或以某個流程為基底建出來,只有你的組織看得到。

## 常用操作

- **建立流程**:按「建立流程」,填**流程 key** 與名稱。流程 key **建立後不能修改**(小寫英文開頭,只能用小寫英文、數字、底線)。
- **以此為基底建流程**:選一個基底版本,填新的 key 與名稱;建好後帶著一份草稿。共用流程的審核者條件只能用權限與組織;想改成你組織的角色或指定某幾個人,就以它為基底建流程再修改。
- **設計**:
  - 先在上方選**檢查用表單**:設計時用來對照的表單,列出可選的欄位、驗證審核者欄位與跳過條件。實際送出時以綁定的表單為準,綁定時會再驗一次。檢查用表單會跟著草稿一起存;新開的草稿會先帶入第一張綁了這個流程的表單。
  - 點流程圖上的關卡,在右側設定名稱、**審核者**、**會簽**、**允許退回修改**、**跳過這一關**、**自動通過**、**逾時提醒**與**知會**。
  - 審核者有三種:
    - **人員條件**:符合條件的人。右側顯示條件的白話摘要,按「編輯條件」在跳窗裡設定:欄位可選使用者、角色、所屬組織、權限,用「全部成立 / 其中一個成立」組合,可以再加群組。所屬組織可以選特定組織,或「單據所屬組織」(送出這張單的組織)、表單裡的組織欄位、「最上層組織」。例如「角色 屬於 店長 且 所屬組織 屬於【單據所屬組織】」= 只交給那家店的店長。按「套用」才會寫回這一關。共用流程的條件只能用「權限」與組織(不能選特定組織)。
    - **表單欄位**(送出時表單裡選的那個人;從檢查用表單的使用者欄位挑,沒選檢查用表單時會提示「請先選檢查用表單」;檢查用表單裡沒有可挑的欄位時,會提示你先到表單設計器加一個資料來源為「使用者」的引用欄位並發布)。
    - **主管**:從申請所屬的組織往上找,第 1 層是最近的一組主管;主管在「組織管理」設定。
  - 會簽:
    - **任一人核准即過**:這一關第一個做決定的人說了算 —— 他核准就過關,他駁回或退回就照他的決定;之後其他人的決定不影響結果。
    - **全部核准才過**:每個人都核准才過關;只要有人駁回或退回,就照那個決定。
  - **跳過這一關**(符合任一項就跳過;兩項都不勾 = 不跳過):
    - **申請人屬於這些組織**:看申請人所屬的組織(全部,不是只看目前組織)。可以選「最上層組織」,或指定組織;勾「包含下層」時,屬於這些組織底下的組織也算。共用流程只能選最上層組織。
    - **符合條件**:用公式判斷,例如「天數 ≤ 1」就跳過人資關。欄位來自檢查用表單,沒選時欄位下拉會提示「請先選檢查用表單」。
    - 被跳過的關卡沒有人核准,也不會經過核准前的檢查;時間軸會寫出是哪一項成立。
  - **自動通過**(預設都是照常審核):
    - **申請人是這一關的審核者時**:選「自動通過」就記成申請人核准;照常審核則不會派給申請人自己。
    - **審核者已在前面的關卡核准過時**:這張單這一輪更早的關卡已經核准過的人,這一關自動記成他核准。退回後重新送出會重新算。
    - 多人會簽時只算他那一票;自動通過照樣經過核准前的檢查,沒通過就照常審核,時間軸會寫出原因。
  - **逾時提醒**(預設關閉):開啟後設定「超過幾小時未處理 → 通知審核者」與「超過幾小時 → 同時通知『通知對象』」,通知對象預設是可以處理阻擋清單(改派)的人,按「編輯條件」可以改。第二個時數要大於第一個,否則不能存草稿。時數含夜間與假日,從任務交給目前的審核者起算;**只提醒,不會自動核准或駁回**。
  - **知會**:不用審核、只通知的人,可以唯讀查看這張單據。來源和審核者一樣有三種(人員條件、表單欄位、主管),預設「不知會」。
    - **關卡的知會對象**:這一關通過或被跳過時收到通知。
    - **整個流程的知會對象**:點流程圖的空白處(或還沒選任何關卡時),右側就是「整個流程」的設定;已經選了某一關時,按右側上方的「回到整個流程設定」也可以回來;單據完成、被駁回或被作廢時收到通知。關卡的知會對象想知道最後結果,就把他也加進整個流程的知會對象。
    - 退回修改、撤回都不會知會;退回後重新送出,再通過那一關時,關卡的知會對象會再收到一次。
  - 「在後面加一關」加在這一關之後;「從此關分流」讓這一關通過後同時交給好幾條分支(例如財務、法務、採購)審,**全部分支都通過**才會在匯合點會合,之後可以結束或再接一關。分支裡可以再加關卡,但不能再分流。
  - 拖曳關卡可以調整順序或移到別條分支;也可以用屬性面板的按鈕:
    - **上移 / 下移**:和同一條線上(主線或同一條分支裡)的前一關或後一關交換順序。
    - **移到分支**:流程裡已經有分流時才會出現,把這一關搬到你選的那條分支的最後。流程走到分流點後,各分支同時開始審,全部分支都通過才在匯合點會合、往下走;所以搬進分支的關卡會和其他分支的關卡同時進行,不是排在它們前後。
    - 刪除一關時前後會自動接上;刪掉分支唯一的一關就是刪掉那條分支。
  - 「檢查結果」隨時列出錯誤與警告,點一下會選中出問題的那一關(整個流程的知會對象的問題,點了回到「整個流程」的設定)。有錯誤不能發布,警告可以。
  - 按檢查用表單旁的**檢查**做一次完整檢查(包含指定的人是否還在、表單欄位是否存在),結果依關卡列出,點一筆會選中那一關並打開右側設定。沒選檢查用表單時,跳過條件沒有對照的表單,只做結構檢查;審核者的「表單欄位」來源仍以各自的表單驗。檢查用表單不存在或還沒有發布版本時,會列出錯誤並擋發布。
  - 改完按「存草稿」。
- **版本**:在「流程版本」頁籤,草稿那一列按「發布」,填變更說明;目前版本按「退役」後,綁這個流程的表單會暫時送不出去,直到再發布新版。「與上一版差異」列出新增、移除、變更的關卡,以及整個流程的知會對象有沒有新增、移除或變更;任一版本都可以「以第 N 版開草稿」。
  - **檢視 vN**:以唯讀方式打開已發布或已退役的版本,可以點關卡看設定、按「檢查」看結果,但不能修改或存。還沒有草稿時,旁邊可以「以 vN 為基底開新草稿」。檢視時,草稿的設計不會不見,按「關閉檢視」就回到草稿。
  - **刪除草稿**:不要這份草稿了就刪掉(會先請你確認;設計器裡還沒存的改動也會一起丟掉)。已發布的版本不受影響,之後可以再開新草稿。
  - **匯出專案設定**(只有系統管理員在共用流程目前發布的版本上看得到):把這一版的設計下載成一個設定檔,交給開發人員放進專案,其他環境就會有同一份流程。填**版本識別**(小寫英文或數字開頭,可用小寫英文、數字、底線、連字號,最長 64 個字;每次修正後重新匯出都要換一個新的)與**發布說明**,按「下載設定檔」。只匯出這一版的設計內容,不會更動任何資料;人員、角色、流程提供給哪些組織、表單綁定都不會被帶走。這一版的審核者條件有指定使用者、角色或特定組織、或用到還沒一起交付的表單時,不會下載,畫面會列出是哪一關與原因;請開新草稿修正後發布,再匯出新的版本。
- **阻擋清單**:頁首的「阻擋清單」列出卡住的單(見下方)。

## 阻擋清單

- **阻擋**:某一關找不到可以審的人(例如沒有人符合審核者條件、主管沒設),或審核者被停用、離開組織,這張單就停在那裡等你處理,系統**不會自動換人或跳過**。
  - **改派**:把卡住的任務交給另一個人。
  - **新增審核者**:那一關完全找不到人時,指定一位。
  - 申請人自己、以及已經在這一關的人不能選。
- **需要推進**:處理過程中斷過、還有步驟沒完成的單。按「重試推進」讓系統接著做完,重按幾次結果都一樣。
- 清單只列單的標題、申請人和卡在哪一關,不顯示申請的填寫內容。

## 重要規則

- **進行中的審核不受改版影響**:已經送出的單照它送出時的流程版本走完;改版、退役只影響之後送出的單。
- **已發布過的關卡 key 不能改**。
- **「草稿已被別人更新,請重新載入」**:有人同時在改同一份草稿,後存的人會被擋下。
- **有未存的變更時換流程**,會先問你要留下、放棄還是先存草稿;發布時如果還有沒存的變更,發布的是上次存的草稿。
- 共用流程的建立與提供給各組織,由系統管理員處理。
