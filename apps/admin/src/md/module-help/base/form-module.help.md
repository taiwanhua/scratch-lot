# 表單模組

## 這個模組做什麼

用表單填寫、保存資料。要填哪些欄位由「表單」決定 —— 表單由管理者在「表單管理」設計並發布之後才會出現在這裡,所以不同組織看到的欄位可能不一樣。表單綁了審核流程時,送出後會依流程一關一關審核,**審核通過才算完成**。

畫面共三頁:**清單**(這一頁)、**新增 / 編輯**、**詳情**。清單上每一列的操作會帶你到另外兩頁。要經過審核的單也會出現在「申請中心」的「我的申請」。

## 常用操作

- **搜尋**:輸入關鍵字比對每一筆的**標題**。
- **篩選**:可依「表單」與「狀態」篩選,換條件會回到第一頁。
- **新增**:按「+ 新增」。現在可填的表單只有一張時直接進入填寫;有好幾張時先選一張。按鈕是灰的代表目前沒有可以填寫的表單。
- **明細列**:有些欄位是一張表格(例如採購品項),按表格下方的「+ 新增一列」加一列,每一列右邊有「上方插入一列」「上移」「下移」三個小按鈕,以及「複製」與「刪除」;第一列不能再上移、最後一列不能再下移;到了最多列數就不能再加、插入或複製。小計、合計這類欄位會跟著你填的數字自動算。錯誤會標在出錯的那一格,列數不夠或太多的提示在表格下方。用手機看時,每一列會變成一張卡片。看修訂差異時,明細會逐列標示「新增 / 刪除 / 移動 / 改值」。
- **帶入資料**:表單有設定帶入時,填寫頁上方會出現「帶入資料」。選一筆既有資料後,勾選要帶入的欄位(本欄已經有值的會提醒「會覆蓋」),按「帶入」。帶進來的值之後還可以自己改。
- **存草稿 / 送出**:「存草稿」先存起來下次再填,草稿只有你自己看得到。有些表單設定成不能存草稿,填寫頁就不會出現「存草稿」,只能填好直接送出。「送出」會一次完成存檔與送出:不用審核的表單送出後就是「已完成」;要審核的表單送出後變成「審核中」。新增時送出沒成功(例如有欄位要修正)不會留下任何資料;從既有的草稿或被退回、撤回的單送出沒成功時,原本那一筆照舊留著。兩種情況畫面上填好的內容都還在,改好再送一次即可。
- **修改已完成的資料**(不用審核的表單):在編輯頁按「儲存修改」。每改一次都會留下一筆**修訂紀錄**。修訂紀錄累積到容量上限時就不能再修改;走審核流程的表單另有修改次數上限,到了請建立新的申請。
- **看審核進度**:在詳情頁下方的「審核」區塊,看得到目前在哪一關、每一關由誰審、誰已經核准,以及完整的審核歷程。
- **撤回**:還沒有任何人審過之前,可以在詳情頁按「撤回」,改好再送。
- **被退回修改**:狀態變成「已退回」時,到編輯頁改好再送出,會從第一關重新審核。
- **作廢 / 複製為新單**:審核通過的單不能再改。要更正就按「作廢」(要寫理由,不需要主管同意),再在詳情頁按「複製為新單」,改好重新送出。
- **詳情**:看這一筆的內容與附件(點檔名下載)。按標題列的「修訂紀錄」可以切換檢視某一次修訂,或看它和前一次修訂差在哪裡。
- **刪除**:清單或詳情頁都可以刪,確認後才真的刪除,無法復原。

## 狀態

| 狀態   | 意思                                               |
| ------ | -------------------------------------------------- |
| 草稿   | 存了還沒送                                         |
| 審核中 | 正在審;標「待處理」表示某一關暫時卡住,等管理者處理 |
| 已退回 | 審核者請你修改                                     |
| 已撤回 | 你自己收回                                         |
| 已完成 | 不用審核的表單:已送出;要審核的表單:審核通過        |
| 已駁回 | 不通過,這張不能再改                                |
| 已作廢 | 通過後作廢了                                       |

## 重要規則

- **看不到某個欄位是權限關係**:有些欄位要另外取得權限才看得到或才能修改;看得到但改不了的欄位會顯示為唯讀並附說明。
- **有些欄位會自己算**:計算欄位不用填,依其他欄位自動算出;需要的欄位還沒填時顯示「—」。有些欄位會依你填的內容才出現或變成唯讀;沒出現的欄位不會存下,也不算進合計(例如沒出現的明細不計入總額)。
- **有些欄位會先幫你填好**:新增時會自動帶入預設值;你還沒改過它之前,它用到的欄位變了會跟著更新,你一改就照你的值。
- **日期**與**日期時間**以你的組織的時區顯示與填寫:日期顯示成「年-月-日」,日期時間再加上「時:分」。上傳欄若限制了檔型或大小,選到不符的檔案會直接提示。
- **「這筆資料已被別人更新,請重新載入」**:你在編輯的期間,這一筆被別人(或你在另一個分頁)改過了。按「重新載入」取得最新內容再改。
- **表單停用或改版不影響舊資料**:已經存在的資料照原本填寫時的表單內容顯示;表單不能再新增時,既有資料仍然看得到。管理者可以把舊資料改成新版表單,這時修訂紀錄會多一筆「某人 於 某時 升級到第幾版」,之前的修訂仍照當時的表單顯示。
- **審核中的內容不能改**:要改請先撤回(還沒人審過時),或等退回後再改。
- **送出時被擋下**:畫面顯示審核流程已移除、尚未發布或設定有誤時,請聯絡管理員。
- **看得到的按鈕就是你做得了的事**:某一列沒有「編輯」或「刪除」,代表你對那一筆沒有該權限;審核通過的單沒有「編輯」,只有「作廢」。
- 看得到哪些資料,由你的**可見範圍**與資料範圍規則決定;審核你的人只看得到他審的那一份內容。
