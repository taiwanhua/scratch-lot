# 通知設定

## 這個模組做什麼

設定「負責人提醒」要通知誰,以及有提醒時間的通知要提前幾天、幾點寄。負責人提醒是系統發現需要有人處理的狀況時送出的通知(例如列印代理程式離線),收件人依條件決定;你可以在這裡調整條件。

有些通知會在某個日期前、逾期後或每個月固定一天提醒(依通知類型而定),這些通知的提醒時間也在這裡調整;日期本身(例如到期日)照各筆資料,不在這裡設定。

待你審核、申請結果、知會這類通知會直接送給當事人(審核者、申請人、知會對象),不在這裡設定;有提醒時間的當事人通知會列在清單上,但只能調整提醒時間。

頁面下方的「側欄數字」可以調整誰看得到側欄模組名稱旁的數字(例如申請中心待你處理的件數)。

## 畫面怎麼操作

- 清單一列一種通知類型,依序是**通知類型**、**組織範圍**、**收件人**、**提醒時間**。用上方的搜尋框可以依名稱找類型。
- **組織範圍**由通知類型決定,不能修改,例如「觸發事件的組織含上層」= 發生狀況的那個組織,以及它的上層組織。
- **收件人**是一行條件摘要;還沒調整過的會標「預設」。收件人由事件決定的通知顯示「由事件決定」(括號內是收件人說明),不能調整。
- **提醒時間**是目前的設定,例如「到期前 30、7 天及當天 09:00」「隔天起每天 09:00」「每月 3 號 09:00」;還沒調整過的會標「預設」。顯示「—(發生時)」的通知在事情發生時就寄,沒有提醒時間可調。
- 按「編輯」打開編輯框,這種通知能調整什麼就出現哪幾塊:「收件人」「提醒時間」,兩塊各有自己的「還原預設」。
- 「收件人」那塊:條件列由左到右是**欄位 → 條件 → 值**,欄位可選:
  - **使用者**、**角色**:值欄位直接輸入就會篩出候選,選中的會變成小標籤,點標籤上的「×」移掉。
  - **權限**:條件顯示「持有」,值是一棵可搜尋的模組 / 權限樹,勾要的權限即可。
- 「+ 條件」加一列條件,「+ 群組」加一個括號,群組裡還可以再加一層,最多三層;「組合」選 AND(全部成立才通知)或 OR(其中一個成立就通知)。
- 「提醒時間」那塊依通知不同,有三種寫法(寫法由通知決定,不能換):
  - **某日期前幾天**:提前天數可以填好幾個(例如 30、7、0),0 = 當天;按「+ 加一個」多加一個天數,按天數旁的「×」移掉。
  - **逾期後每天**:只設寄送時間,逾期的隔天起每天寄。
  - **每月第幾天**:填 1–31;那個月沒有這一天就在月底寄(例如填 31,2 月在 2 月最後一天寄、4 月在 4/30 寄)。
  - **寄送時間**可以從選單挑或直接輸入,只能是 15 分鐘一格(例如 09:00、09:15);不是的話儲存時會提示。
- 按「儲存」生效,只會存你改過的那一塊。條件沒填值或群組是空的,會標在出問題的那一列;儲存後才發現的問題(例如指定的人不在你的組織內)也會標回那一列;提前天數超出範圍或重複,會標在那一格。
- 編輯框裡每一塊的「還原預設」只還原那一塊,另一塊不受影響。
- 清單上的「還原預設」會先告訴你預設的收件人與提醒時間,確認後兩塊一起改回預設、標回「預設」;都沒調整過的類型不能按。

### 側欄數字

- 一列一個數字,依序是**模組**、**數什麼**、**誰看得到**。要數什麼由系統決定,不能新增列。
- **誰看得到**一律要先能進入那個模組;還沒調整過的會標「預設」,預設是「可進入這個模組的人」,有些數字預設還要持有某個權限(摘要會寫出來)。
- 按「修改」打開條件編輯框,寫法跟收件人一樣(欄位可選使用者、角色、權限);按「儲存」後,能進入那個模組、而且符合條件的人才看得到數字。
- 「還原預設」會先告訴你預設是誰看得到,確認後改回預設;沒調整過的不能按。
- 數字本身還是只算你看得到的資料;這裡只決定「誰看得到這個數字」。
- 條件裡的「權限」只算真的被授予的權限,能看到所有頁面的最高管理員也一樣;規則跟收件人的條件相同。

## 重要規則

- 收件人 = **組織範圍內**、而且**符合條件**的人,兩者都要成立。
- 一定要設條件,不能選「所有人」;條件裡也沒有「所屬組織」—— 範圍已由組織範圍決定。
- 只能指定你的組織內的使用者與角色。
- 改完之後,下一次發出這種提醒就照新的條件;已經送出的通知不受影響。
- 提醒時間的範圍:提前天數 0–365、最多 5 個、不能重複;每月第幾天 1–31;寄送時間 15 分鐘一格。
- 提醒時間以最上層組織的時區計,時間到了之後通常 15 分鐘內寄出;系統暫時沒有寄出時,6 小時內會補寄,超過就不再補。同一個時間點只寄一次。
- 改了提醒時間之後,今天已經過了的新時間不會補寄,從下一個時間點開始照新設定(例如 08:30 把 09:00 改成 08:00:今天 08:00 不補寄、今天 09:00 也不寄,明天起 08:00)。
- 提醒時間是整個組織一套,不能依各組織 / 下層組織分開設定。
- 收件人自己可以在個人設定裡關掉某種通知的部分管道(站內、Email);這裡只決定「通知誰」。
- 沒有編輯權限的人只能查看,看不到「編輯」「修改」與「還原預設」。目前所在的組織不屬於任何最上層組織時,只看得到預設值、不能調整,要先切換到要設定的組織。
