# 通知設定

## 這個模組做什麼

設定「負責人提醒」要通知誰。負責人提醒是系統發現需要有人處理的狀況時送出的通知(例如列印代理程式離線),收件人依條件決定;你可以在這裡調整條件。

待你審核、申請結果、知會這類通知會直接送給當事人(審核者、申請人、知會對象),不在這裡設定。

## 畫面怎麼操作

- 清單一列一種通知類型,依序是**通知類型**、**組織範圍**、**收件人**。用上方的搜尋框可以依名稱找類型。
- **組織範圍**由通知類型決定,不能修改,例如「觸發事件的組織含上層」= 發生狀況的那個組織,以及它的上層組織。
- **收件人**是一行條件摘要;還沒調整過的會標「預設」。
- 按「編輯」打開「編輯收件人」:條件列由左到右是**欄位 → 條件 → 值**,欄位可選:
  - **使用者**、**角色**:值欄位直接輸入就會篩出候選,選中的會變成小標籤,點標籤上的「×」移掉。
  - **權限**:條件顯示「持有」,值是一棵可搜尋的模組 / 權限樹,勾要的權限即可。
- 「+ 條件」加一列條件,「+ 群組」加一個括號,群組裡還可以再加一層,最多三層;「組合」選 AND(全部成立才通知)或 OR(其中一個成立就通知)。
- 按「儲存」生效。條件沒填值或群組是空的,會標在出問題的那一列;儲存後才發現的問題(例如指定的人不在你的組織內)也會標回那一列。
- 按「還原預設」會先告訴你預設的收件人條件,確認後改回預設、標回「預設」;沒調整過的類型不能按。

## 重要規則

- 收件人 = **組織範圍內**、而且**符合條件**的人,兩者都要成立。
- 一定要設條件,不能選「所有人」;條件裡也沒有「所屬組織」—— 範圍已由組織範圍決定。
- 只能指定你的組織內的使用者與角色。
- 改完之後,下一次發出這種提醒就照新的條件;已經送出的通知不受影響。
- 收件人自己可以在個人設定裡關掉某種通知的部分管道(站內、Email);這裡只決定「通知誰」。
- 沒有編輯權限的人只能查看,看不到「編輯」與「還原預設」。
