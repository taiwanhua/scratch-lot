# 印表機管理

## 這個模組做什麼

管理店內的收據機(58mm 網路收據機),讓各單據的 [列印] 按鈕印得出來。畫面有三個分頁:

- **印表機**:每台收據機的名稱、IP 位址、由哪一台代理程式負責、是不是這個組織的預設印表機,以及目前狀態。
- **代理程式**:裝在店內電腦上、負責把列印工作送到收據機的小程式。上方可以下載安裝檔。
- **列印紀錄**:每一次列印的時間、單據、印表機、第幾次、結果與操作者,新的在最上面。

列印的路線是:任何裝置按 [列印] → 系統 → 店內電腦上的代理程式 → 收據機。所以每家店至少要有一台裝好代理程式、一直開著的電腦;平板、手機按 [列印] 也走同一條路。

## 第一次設定

1. 到「代理程式」分頁,按「新增代理程式」,選所屬組織(哪一家店)、取個名稱(例:櫃台電腦),按「建立」。畫面會顯示**伺服器網址**與 **8 碼配對碼**,旁邊各有「複製」。配對碼 **10 分鐘內有效,而且只顯示這一次**;來不及用就對那一台按「重新配對」拿新的。
2. 在店內電腦安裝代理程式(見下一節),安裝時貼上伺服器網址與配對碼。裝好後,代理程式那一列會顯示「已連線」。
3. 到「印表機」分頁,按「新增印表機」:選所屬組織,填名稱、收據機的 IP 位址與 Port(一般是 9100),選負責的代理程式,需要的話勾「設為這個組織的預設印表機」,按「儲存」。
4. 對那台印表機按「測試列印」,確認印得出來。

## 安裝代理程式

**選哪一台電腦**

- 一家店只需要**一個**代理程式,建議裝在每天都會開著的**收銀電腦**上 —— 可以和收銀共用同一台,代理程式在背景執行,不影響收銀。
- 電腦和收據機要在**同一個區域網路**。
- 收據機要設**固定 IP**:建議在路由器保留 IP(把收據機的 MAC 綁定一個固定 IP);路由器不能設時,才用收據機自己的設定頁設定,注意不要和其他設備重複。
- 電腦要**關閉睡眠**:到電腦的電源(能源)設定,把「進入睡眠」設成「永不」;螢幕可以照常關閉。電腦關機或睡眠時無法列印,畫面會顯示「失敗:代理程式離線」。

**下載**

「代理程式」分頁上方會顯示最新版本與四個下載按鈕;依你目前用的電腦,建議的那一個會標「(建議)」。請在**要安裝的那台電腦**上下載。

| 電腦                   | 下載                    | 安裝方式                                                  |
| ---------------------- | ----------------------- | --------------------------------------------------------- |
| Windows                | Windows x64             | 解壓縮後,在「安裝.bat」上按右鍵 →「以系統管理員身分執行」 |
| Linux                  | Linux x64 / Linux arm64 | 解壓縮後在資料夾裡執行 `sudo ./install.sh`                |
| Mac(Apple 晶片,M 系列) | macOS arm64             | 解壓縮後在「終端機」進到資料夾執行 `sudo ./install.sh`    |

安裝程式會詢問**伺服器網址**與**配對碼**,貼上剛才複製的內容即可。裝好後代理程式會設成開機自動執行,當掉也會自動重新啟動。

**Windows 跳出「Windows 已保護您的電腦」時**:這個程式沒有程式碼簽章,第一次執行「安裝.bat」或程式本身時可能出現。確認檔案是從本頁下載的,按「其他資訊」→「仍要執行」。如果檔案被標成「已封鎖」,先在 zip 檔上按右鍵 →「內容」→ 勾「解除封鎖」→「確定」,再解壓縮。

**Mac 第一次被擋下時**:這個程式沒有 Apple 開發者簽章,第一次執行可能出現「無法打開,因為無法驗證開發者」。用 `sudo ./install.sh` 安裝時會先解除下載帶來的隔離標記;如果仍被擋下,到「系統設定 → 隱私權與安全性」最下方按「仍要打開」,或在「終端機」執行 `xattr -dr com.apple.quarantine <解壓後的資料夾>`,再執行一次安裝。不支援 Intel 晶片的 Mac。

**更新**:看到代理程式的版本旁標「請更新」時,在那台電腦下載新版、再執行一次安裝即可;原本的配對會保留,不必重新配對。

## 常用操作

- **測試列印**:對印表機按「測試列印」,會印出一張測試頁(字體大小、對齊、表格、長文字換行、條碼、QR code 與切紙)。結果直接顯示在對話框:
  - 成功:「已印出測試頁」,請核對紙上的各項目。
  - 缺紙:補紙後按「重試」。
  - 代理程式離線:會顯示最後連線時間;確認那台電腦有開機、沒有睡眠、網路正常,再按「重試」。
- **編輯印表機**:改名稱、IP 位址、Port、負責的代理程式(只能換成同一個組織的)、是否預設;關掉「啟用」就停用這台印表機,列印按鈕上就選不到它。
- **重新配對**:對那一列按「重新配對」。舊的配對**立刻失效**,畫面會顯示新的伺服器網址與配對碼(10 分鐘內有效);印表機設定都會保留。拿到新配對碼後,依情況做:
  - **換了一台電腦**,或**上次還沒裝好、配對碼就過期了**:在要用的那台電腦執行安裝程式(見「安裝代理程式」),貼上新的伺服器網址與配對碼。
  - **同一台電腦、已經裝好**(例如懷疑金鑰外流而重新配對):再執行一次安裝程式會沿用舊設定,不會換成新配對碼。請以系統管理員身分執行 `print-agent pair --server <伺服器網址> --code <新配對碼> --force`(Windows 在 `C:\Program Files\print-agent\` 資料夾裡執行;Linux、Mac 在指令前加 `sudo`;Linux 完成後再執行 `sudo chown print-agent:print-agent /etc/print-agent/config.json`),然後重新啟動代理程式的服務(或重新開機)。
- **停用代理程式**:按「停用」。停用後那台電腦再也連不上,它負責的印表機在列印按鈕上選不到,還沒印的工作都會標失敗。**停用之後不能再啟用**;要再用就新增一個代理程式,再到「印表機」分頁把印表機改由新的代理程式負責。
- **看已停用的代理程式**:代理程式分頁預設只列啟用中的;打開上方「顯示已停用」才會一起列出。
- **列印紀錄**:可以依印表機、結果篩選。「次數」顯示這張單據第幾次印,補印的會標「補印」。

## 狀態怎麼看

**代理程式**

| 狀態     | 意思                                                           |
| -------- | -------------------------------------------------------------- |
| 已連線   | 2 分鐘內有回報                                                 |
| 離線     | 超過 2 分鐘沒有回報(電腦關機、睡眠或斷網)                      |
| 等待配對 | 剛新增或剛重新配對,還沒在電腦上用配對碼完成配對                |
| 已停用   | 已停用,不能再使用                                              |
| 請更新   | 標在版本旁:這台電腦上的代理程式不是最新版,建議下載新版重新安裝 |

**印表機**

| 狀態   | 意思                                          |
| ------ | --------------------------------------------- |
| 正常   | 代理程式回報收據機正常                        |
| 缺紙   | 收據機沒紙了                                  |
| 連不上 | 代理程式連不到收據機(確認收據機有開、IP 沒變) |
| 離線   | 負責的代理程式離線,看不到收據機的狀態         |
| 未回報 | 剛新增,代理程式還沒回報過                     |
| 已停用 | 這台印表機已停用                              |

**列印紀錄的結果**:等待中、已送出(代理程式已接手)、已印出、失敗(後面會寫原因,例如缺紙、代理程式離線、未收到列印結果)。「未收到列印結果」表示代理程式接手後沒有回報 —— 紙可能已經印出來了,請先確認再決定要不要補印。

## 重要規則

- 只有看得到的組織才會出現在這裡;印表機屬於負責它的代理程式所在的組織。
- 送出列印時代理程式已離線,工作會直接標失敗,不會等電腦開機後才突然印出來;等待超過 2 分鐘沒有被接手的工作也一樣。
- 沒有「新增」權限的人看不到「新增代理程式」「新增印表機」與下載按鈕;沒有「編輯」權限的人看不到「測試列印」「編輯」「重新配對」「停用」。
